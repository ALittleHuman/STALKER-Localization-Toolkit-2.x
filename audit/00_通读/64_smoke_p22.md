## 3. ★★★ 下拉样式的判据：**一律按真值，不按 token 名**（第 10718-10725 行）

> ★★ 判据一律**按真值（token 已经替换完的色值/尺寸）**，**不按 token 名**：
> `stylesheet_for()` 返回的是**已解析**的样式表 —— `@{pad4}` → `4px`、`@{surface2}` → `#2b2f33`。
> 拿 `contains("pad4")` 这种去判是**假判据**（永远红，跟实现对不对无关）。

⇒ 以及"取**最后一条**规则"（`qss_rule_body(..., last=true)`）—— 因为 Qt 是"后写的赢"，
而 `QComboBox, QLineEdit, QSpinBox` 在样式表里出现**两次**（审计 B1-3）。

四条 + 三个派生判据：
- ① `::down-arrow` 只给几何、**不许有 `::drop-down` 规则**（有它 Qt 就不画箭头，实测 0 像素）；
- ①′ **真 combo `grab()` 后在右 14px 里数 `text_dim` 像素 ≥ 6**（实测 15）——
  ★ 注释点明"光量 primitive 会给出**假绿**"；
- ①″ primitive 那一笔**是主题色**（与 ①′ 分工：①′ 证"用户看得见"、①″ 证"那一笔是主题色"）；
- ② 内距 `pad4 pad8` 且**不出现** `pad10`（写回旧值即红）；
- ③ 弹层 `border-radius: 0` + `1px solid`；
- ④ `QMenu` **恰好三条属性**（background=surface2 / relief=flat / 1px solid border），且不引 accent；
- ④′ `QMenu::item:selected` **＝中性灰**、**不许 accent**（"不许系统蓝高亮"）。

## 4. ★★★ B1-2：一个环境变量就能**无声关掉整组断言**（第 10923-10928 行）
