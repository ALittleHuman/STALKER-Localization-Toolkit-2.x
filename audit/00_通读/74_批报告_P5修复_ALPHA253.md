# 批报告：P5 根因修复（ALPHA.253）

**日期**：2026-10-23　**版本**：2.0.0 ALPHA.253（index 253，commit `acd6460`）
**一句话**：P5「插件页空页」的根因**不是**视口/外壳，而是**页容器地址被复用后 `unwrap()` 把活容器判死**
⇒ 整页控件无父 ⇒ 占位页。修复＝把宿主造的容器登记成句柄（`adopt_host_widget`，覆盖写）。


**触发链**：插件页存在 ⇒ 页被反复重建（`render_plugin_slots()` 每个 tool 都 `sync_pages()`）
⇒ 门面控件地址被释放；新页容器**复用**该地址 ⇒ `unwrap()` 把活容器当死句柄
⇒ `resolve_parent()` 返回 null ⇒ 该页所有控件走 `place(nullptr,…)`
⇒ `anything_built=false` ⇒ 占位页 ⇒ **P5 / P16-3c / P17-82 / P16-3b-2 / P4 同时红**。

## 4. 修复

```cpp
// widget_facade_qt.cpp（新增）
void adopt_host_widget(void* widget) {
    if (widget == nullptr) return;
    handle_registry()[reinterpret_cast<plug::UiHandle>(widget)] =
        QPointer<QWidget>(reinterpret_cast<QWidget*>(widget));   // ★ 覆盖写：死项必须被活项替换
}
```
调用点两处（宿主造的两种容器）：`hub.cpp` `sync_pages()` 页容器、`render_plugin_slots()` ④ 面板容器。

- **为什么覆盖写**：否则同一地址下次复用还会被死项遮住；
- **为什么不是 `erase`**：erase 会让悬垂句柄退回"没登记 ⇒ alive()=true"（`handle_alive` 注释里警告的假）；
- **顺带修好的假**：页销毁后插件对**页根句柄**调 `alive()` 以前恒 `true`（没登记），现在正确 `false`。
