# P5 判决性实验：结果与修复（2026-10-23）

> 这是 40 轮通读之后**第一个把假设变成"实证 + 修复 + A/B"**的动作。全程只加观测，不改行为；
> 修复是**一行登记**。结论：**"地址复用 ⇒ unwrap 把活容器判死"成立，已修，A/B 干净。**

---

## 1. 假设（读代码推出来的）

- 页容器 `new QWidget`（`hub.cpp:526`）**从未登记**进句柄表；
- `widget_facade_qt.cpp:253-260` 的 `unwrap()`：**地址在表里但 QPointer 已死 ⇒ 返回 nullptr**；
- 于是容器地址一旦**复用**某个已销毁门面控件的地址 ⇒ 活容器被当死句柄
  ⇒ `resolve_parent()` 返回 null ⇒ 该页**所有**控件无父 ⇒ `place(nullptr,…)` 静默返回
  ⇒ `anything_built=false` ⇒ 占位页 ⇒ P5 红。

| `resolve_parent()` | `resolve` | 追加 `root_in_reg=` / `root_stale=` |
| `place()` 空父分支 | `place_null`（新增） | `parent= child= root= root_stale=` |

## 3. A/B 实测（build 树；`--smoke` 每次 ~16s）

### A. 修前（`plugins/` 里放了 7 枚 `*_page.py`，复刻判据 ④ 的形态）

```
12 次（plugins 空）:  place_null=0  root_stale=0    fails 0/12，1 次失败是非 P5 的 1 条
10 次（7 枚夹具）:    place_null=0  root_stale=**60**（in_reg=30）  **1 次红 8 条**
```

★ 那 1 次红的 8 条正是"插件页里的东西全没了"：
```
P17-82 插件造的 list 自动装了宿主拖放过滤器（列表=0 过滤器=0）
P17-82 插件造的 tree 自动装了宿主拖放过滤器（树=0 过滤器=0）
P17-82 落到插件 list/tree 上 ⇒ 回调收到路径（实得 空）
P16-3b-2 插件页里没找到「自带滚动的长列表区」（视口=0 条子量程=-1）
P16-3c 按钮要挂上左键动作菜单、且两项（返回 1 / 菜单 0 / 项数 -1）   ← 我们那个红
P4 拖入区域的回调没收到本机路径（handled=0）
P4 Python worker 的 progress(100) 没到宿主进度条（实得 无进度条）
```

★ 现场 trace（run08，同一页连续 14 条）：
```
门面L2夹具页|resolve|parent_arg=0 resolved=0 current_root=0 same=0 … root_in_reg=1 root_stale=1
门面L2夹具页|place_null|parent=0 child=29113bc1a80 root=29113bc0970 root_stale=1
```

`current_root=0`（unwrap 后为空）而 `root=29113bc0970` 是**同一个地址**
⇒ 容器活着、表里被判死。**假设成立，且就是这一页。**

### B. 修后（同一份夹具、同一台机器）

```
10 次: place_null=0  root_stale=**0**  in_reg=932/次  **0 fails（10/10 绿）**

```

⇒ `root_stale` 从 **60 → 0**，那 8 条红**没再出现**。

## 4. 修复（`adopt_host_widget`）

```cpp
// widget_facade_qt.cpp
void adopt_host_widget(void* widget) {
    if (widget == nullptr) return;
    const plug::UiHandle handle = reinterpret_cast<plug::UiHandle>(widget);
    handle_registry()[handle] = QPointer<QWidget>(reinterpret_cast<QWidget*>(widget));  // ★ 覆盖写
}
```
调用点两处（宿主**造的两种容器**，同一个坑）：
- `hub.cpp` `sync_pages()` 的页容器；
- `hub.cpp` `render_plugin_slots()` ④ 面板循环的面板容器。

★ **为什么是"覆盖写"而不是"不存在才登记"**：死项必须被活项替换掉，
否则下一次复用同一地址还会被遮住。同理也**不是** `erase` —— erase 会让悬垂句柄退回
"没登记 ⇒ 非空 ⇒ alive()=true"（那正是 `handle_alive` 注释里警告的假）。

★ **顺带修好的一个假**：页销毁后，插件对**页根句柄**调 `alive()` 以前恒 `true`
（它没登记）⇒ 现在**正确变 false**。

## 5. 这个实验顺带回答的三件事

1. **P5 的红不是"视口没套上"**，是"整页控件都没挂上" —— 判据报错词误导了 40 轮；
2. **`place_null` 是空页的唯一出口**，而它修前**一行痕迹都没有**（现在有了）；
3. **`check_package_fixture_pages.py` 的 ③/④ 差异**（plugins 空 vs 抬 7 枚）正是这条的触发条件 ——
   所以 `8/20` 那种数字里，**至少一部分**来自这里。
