## 5. ★★★ S-01：`alive()` 的真凭据（第 8657-8697 行）

修前事实：
> `alive` 的实现是 `unwrap(widget) != nullptr`，而 `unwrap` 就是 `reinterpret_cast<QWidget*>`
> —— **QWidget 销毁后指针不会变 null** ⇒ 插件缓存过句柄再问 `alive()` **永远得到 true**，
> 随后解引用就是**悬垂访问**。

修法：每个发出去的句柄登记 `QPointer`（析构自动置空）⇒ alive 有真凭据；
同时 `unwrap()` 对"已登记但已死"的句柄返回 nullptr。

判据三步（很干净）：
```cpp
check(alive(h));            // 活着 ⇒ true
delete reinterpret_cast<QWidget*>(h);
check(!alive(h));           // 已销毁 ⇒ false（修前恒 true）
set_text(h, "x");           // 必须**不崩**
check(label(...) 还能造且 alive);   // 证明上一步没把内部状态弄坏
```
