# 2.0.0 联网与在线更新（宿主内置）

本文件描述 **BETA.234+** 的实现边界：联网、更新检查、清单/更新包下载由本体 C++ 负责；
联网插件 `xrkit.net_http` 不再是运行时依赖。

## 1. 总开关

`user.ltx`（实际文件名 `xrkit_user.ltx`）：

```ini
[network]
enabled=1
```

入口：

```text
工具 → 联网功能（勾选）
```

关闭后：

- `core::http_get` / `http_download` 直接返回“联网功能已关闭”；
- 宿主“检测更新”拒绝；
- 插件管理器检查/安装更新拒绝；
- 联网插件的检查/下载/更新入口也拒绝（如果仍安装）。

判据：

```text
tests/check_network_toggle.py
enabled=0 ⇒ 本地 HTTP 服务端 0 次请求
enabled=1 ⇒ 1 次请求
```

## 2. 宿主 HTTP

`include/xrkit/core/http.h`

- `http_get(url, timeout, max_bytes)`
- `http_download(url, path, timeout, max_bytes)`

实现：Windows WinHTTP；系统代理、系统证书、跟随重定向、超时、大小上限；
失败删除半文件；不关闭证书校验。

CLI：

```bat
xrkit_cli --http-get <url>
xrkit_cli --http-download <url> <out>
```

## 3. 本体更新

帮助菜单：

```text
检测更新
```

流程：

```text
GitHub Release API（releases/latest）
→ version 比较
→ 用户确认
→ http_download
→ sha256
→ 解压（tar / PowerShell Expand-Archive）
→ 启动 xrkit_updater.exe
→ 当前进程退出
```

`xrkit_updater.exe` 仍是独立进程：

- 等旧进程退出；
- 备份到 `%TEMP%`；
- 替换；
- 启动新版本；
- 存活 ⇒ commit；
- 失败 ⇒ rollback；
- 自身 handoff 到事务外 runner，避免文件锁。

## 4. 插件更新

插件管理器：

- “检查插件更新” → `core::http_get plugins.json`；
- “安装所选更新” → 下载 zip、sha256、解压、`--plugin-update apply/activate`；
- 安装后提示重启。

插件目录更新事务：

- 更新前写入 `plugins.disabled`；
- 整目录备份/替换；
- 启动时 `.xrkit_update` 确认：加载成功 commit，失败 rollback；
- 原本禁用的插件更新后仍禁用。

## 5. 仓库边界

- 本体：`STALKER-Localization-Toolkit-2.x`
- 联网插件（可选/旧兼容）：`STALKER-Localization-Toolkit-2.x-Network-Plugin`

本体不再要求插件提供网络；插件仓库保留 `net_http.py` 仅作旧版本兼容/可选能力。

## 6. 判据入口

```text
py tests/check_network_toggle.py
py tests/check_host_offline.py
SHELL-SMOKE --smoke
```

`check_host_offline.py` 仍断言包内无 `plugins_net`/`net_http.py`；
联网能力由本体 `Qt`/WinHTTP 提供，不再以插件文件形式随包。
