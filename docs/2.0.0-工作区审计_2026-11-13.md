### 3. 更新检测当前实现

`src/shell/host_update.cpp`：

```text
kApiDirect = .../releases/latest
kApiProxy  = https://gh-proxy.com/https://api.github.com/.../releases/latest
```

只查 `/releases/latest`，没有：

- `/releases?per_page=100`；
- `prerelease` 过滤；
- 测试构建 n 的选择；
- 正式版/测试版分流。

`src/shell/hub.cpp` 版本比较：

```cpp
latest_parts.join('.') > current_parts.join('.')
```

这是字符串字典序，不是 x.y.z.n 语义比较。

结论：

```text
当前代码无法实现“正式版不升测试版、测试版可升后续测试版”
```

### 4. 启动自动检查

`src/shell/main.cpp`：

```cpp
QTimer::singleShot(2000, &hub, [&hub] { hub.check_updates(true); });
```

`check_updates` 内是同步 `http_get`。网络慢时会阻塞 UI。

### 5. smoke

`src/shell/smoke.cpp`：

```text
D2-字体 选择器交互**未覆盖**（smoke 性能修复中）
```

真实 UI 双击正常，属于测试路径问题；但正式包 smoke 覆盖有缺口。

### 6. 发布状态

```text
dist/2.0.0/BETA/243 存在
dist 内无 243 的 app.zip
GitHub releases/latest 当前为空/404
```

所以 243 目前不能作为自动更新目标。

### 7. 绝对路径

成品汉化包只有相对路径：

```text

```

源码中仍有：

- `system_dirs.cpp`：`%SystemRoot%` 空时兜底 `C:\Windows`；
- `third_party_probe.cpp`：测试字体路径；
- `smoke.cpp`：测试夹具路径。

这些不写入成品文件。
