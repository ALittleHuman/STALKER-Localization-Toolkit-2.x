## 4. 插件 C ABI 的 sink 键

### 4.5 `XmlCompareResult` 的 sink 键：认什么、不认什么

- `row_kind` **不落位**（结果结构里没有这个字段）——它是渲染提示，不是比较结果；
- 但**不许静默丢**：宿主不认识的 sink 键必须逐条记进 `unhandled_keys`，由调用方决定报错还是忽略；
- `ids_a` / `ids_b` 按**插件真报上来的 ID 数**算（不能取文本模式的 `id_text_*` 表，那张表在 C ABI 路径上恒空）。

## 5. 过滤语义的两条依据

- 门面侧：`item->text(column)` 是“用户看到的那一格”；筛选必须按它算，不看隐藏列。
- 内置页侧：`matched_paths_` 记录子树里命中的路径集合；父节点是否可见由它决定。
