# 内部契约（维护者）

给改代码的人看的硬口径；用户文档在 `用户手册.md` / `插件开发.md`。

> 插件只支持 Python 文件/目录；`PLUGIN_API = 2` 是 Python API 契约版本（API 1 兼容），不是二进制 ABI。

## 1. 插件 sink 键

- `XmlCompareResult` 的 `row_kind` 不落结构，只作渲染提示；
- 不认识的 sink 键必须逐条进 `unhandled_keys`，不得静默丢；
- `ids_a`/`ids_b` 按插件实际上报的 ID 数算，不能拿文本模式的 `id_text_*` 表（插件路径恒空）。

## 2. 过滤语义

- 门面侧按 `item->text(column)`（用户看到的格子）筛选，不看隐藏列；
- 内置页用 `matched_paths_` 记录子树命中，父节点可见性由它决定。

## 3. 下载与取消（单一实现）

统一入口：`core::DownloadManager`。

- 宿主更新：`HostUpdate::downloadAppUpdate` → Manager；
- 插件同步：`api.host.http_download` → Manager；
- 插件异步：`api.host.http_download_async` → Manager；
- 底层只有 `core::http_download` / `http_download_range`；
- 分片：`<target>.part.N` + `<target>.segments`；
- 取消：`DownloadManager::cancel`；宿主按钮/插件 `http_cancel` 最终都落到它；
- 插件卸载：`cancel_owner(owner)`；
- 完成 job 保留 10 分钟供轮询，之后 join/回收。

**禁止**再新增第二套下载循环、第二套 `.part` 状态机或独立取消标志驱动的下载实现。

## 4. 更新状态

- `pending.json` 只负责安装事务（版本/zip/ready）；
- 下载断点归 Manager，不再用 `pending.json` 兼职；
- `.bak/.tmp` 原子轮换；启动时读 current/bak，损坏回退；
- 多 zip Release 按版本 build 选资产并配对 digest；
- 旧包目录不自动删除。

## 5. 版本模型 C

- `version.json.build_counter` 是唯一先后依据，每次构建 +1；
- 稳定版 `x.y.z`；测试版 `x.y.z.<build>`；
- `kChannel` 只放通道名（BETA/RC/ALPHA），`kBuildNumber` 放全局 build；
- dist 落点 `dist\x.y.z\<通道>\<通道序号>`；
- 包内 `version.txt` 同时写 `index` 和 `build`；
- 测试版只比 build；正式版 > 同版本测试版。

## 6. smoke 与本体

- `xrkit_app.exe` 不含 `smoke.cpp` / `--smoke`；
- `xrkit_smoke.exe` 独立目标，带自己的版本资源/manifest；
- 发布包不带 smoke；`package.ps1` 自检时临时拷入、跑完删除；
- 门禁/脚本使用 `xrkit_smoke.exe`，不要重新给 app 加 smoke 分支。

## 7. 遍历与读文件

- 递归遍历统一用 `fs::collect_tree`，不要新增 `recursive_directory_iterator`；
- 整文件读统一 `core::read_file_capped`，默认 512 MB，超限显式失败；
- 刻意不接：DB 整包读（untrusted_limits）、内部产物回读、atomic_write 备份、日志读取。

## 8. SquashFS 压缩

- 压缩（**读**侧）：xz / gzip / lzo / lz4 / zstd 都能读；
- **写侧只支持 xz（默认）＋ gzip**，读写能力**不对称**；
- 写侧压缩器**没做**：lzo、lz4、zstd 三种；
  - lzo 的原因：minilzo 没有 lzo1x_999；
  - lz4 的原因：要多写 8 字节 options 块（COMPRESSOR_OPTIONS 语义）；
- 默认压缩：写侧默认 xz；**写侧另有 gzip**（已落地，不只是承诺）。

## 9. 文本 sniff

- 决定性 = 证据 >= 2 且 |score| >= 0.15（与 `sniff.cpp` 常量同源）。

## 10. 保留的零调用接口

| 符号 | 原因 |
|---|---|
| `plugin::set_host_facade()` | 宿主门面注入口，未来换实现用 |
| `core::case_fold_ascii()` | ASCII 折叠与 Unicode 折叠语义不同，保留 |
| `Registry::register_format()` | 已接 Python `api.register_format`，不是死代码 |

已删除且不要再加：CLI `--app-update`、三个 C ABI 方法名枚举、`Registry::has_command()`。
