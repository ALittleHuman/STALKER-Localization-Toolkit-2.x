# 插件开发

> 插件 API 是**实验性 Python API**；`PLUGIN_API` 是契约版本（当前 2，API 1 兼容），不是二进制 ABI。
> 仓库里的 `plugins/*_page.py` 是 API 样例（非产品），不承诺生产可用。

## 1. 加载与目录

```text
plugins/
  hello.py                单文件插件
  multi/                  目录插件
    plugin.py             入口（优先于 __init__.py）
    __init__.py
    helper.py
```

- 加载器只扫 `plugins\` **顶层**；
- 单文件：稳定键/禁用键 = 文件名；
- 目录：入口 `<dir>\plugin.py` 或 `<dir>\__init__.py`；稳定键/禁用键 = 目录名；
- 模块名 = 入口名（`.`/`-` 归一化为 `_`）；目录插件按包加载，可 `from . import helper`；
- `plugins.disabled` 记录禁用；被禁用插件不加载并显示原因；
- 跨插件 import 必须在 `PLUGIN_INFO` 赋值后，目标写进 `PLUGIN_INFO["depends"]`；运行时回调里禁止跨插件 import，用 `api.services.call`。

## 2. 最小插件

```python
PLUGIN_API = 2
PLUGIN_INFO = {
    "name": "Hello",
    "version": "1.0",
    "description": "最小示例",
}

def register(api):
    api.log("Hello：已注册")

    def build():
        api.ui.label(None, "你好，这是插件页")
        api.ui.button(None, "点我", lambda: api.log("clicked"))

    api.register_tool("hello", build, 100, "", "示例", "Hello")
```

- `register(api)` 在 UI 主线程调用，不要做重活；
- `register_tool(name, build, order=0, replaces="", subtitle="", title="")`：
  - `name` 全局唯一；`order` 控制页签顺序；
  - `replaces` 写目标 id 才替换，留空是新增页；
  - `build()` 也在 UI 主线程调用，返回 `None` 即可；
- 可选 `headless(api, args)` 供 `xrkit_cli --py-plugin-call` 使用，不能碰控件。

## 3. API 面与线程

| 面 | 用途 | 线程 |
|---|---|---|
| `api.ui` | 控件、对话框、任务壳、树/列表 | 绝大多数只能在 UI 主线程 |
| `api.engine` | 解包/封包、文本、字库、XML、视频、补丁 | worker 可调用 |
| `api.host` | 偏好、进程、路径、HTTP | 见下 |

### 3.1 UI 常用方法

- 控件：`label` / `button` / `row` / `checkbox` / `entry` / `text` / `combo` / `list` / `tree` / `tabs` / `drop_box`；
- 读写：`set_text` / `get_text` / `set_enabled` / `set_checked` / `checkbox_state` / `combo_value` / `combo_set_items` / `set_progress` / `progress` / `log`；
- 树：`tree_set_columns` / `tree_set_root` / `tree_set_children` / `tree_on_expand` / `tree_on_check` / `tree_set_checked` / `tree_checked` / `tree_set_filter` / `tree_filter_hits` / `tree_on_click` / `tree_on_activate` / `tree_on_action` / `tree_select` / `tree_selected_key` / `tree_selected_keys` / `tree_set_expanded` / `tree_expanded_keys`；
- 列表：`list_set_row_count` / `list_set_row_text` / `list_selected_rows` / `list_set_multi`；
- 布局：`pack` / `split` / `split_add_pane`；
- 菜单：`button_on_menu` / `context_menu`；
- 对话框：`ask_directory` / `ask_open_file` / `ask_save_file` / `ask_yes_no` / `pick_font` / `copy_text` / `open_path`；
- 任务：`task_panel` / `task_run` / `task_status` / `task_cancel` / `task_cancel_requested` / `task_on_message` / `on_ui_thread`。

完整名字以 `xrkit_cli --ui-facade` 的 `UIFACADE Ui=` 为准。

### 3.2 线程契约

- worker 里只允许 `ui.task_cancel_requested`、`ui.on_ui_thread`、`ui.post`；其余 `api.ui.*` 会拒绝并记 Warn；
- `ui.post(fn, *args)` 任意线程调用，回调到 UI 线程；页面销毁后先 `ui.alive` 自查；
- 正确姿势：主线程取值 → 纯数据 → `task_run` worker 做引擎调用 → `message` 回主线程 → `task_on_message` 碰控件；
- `api.engine.*` worker 可调；`api.host.pref_get/pref_set` 建议主线程；
- UI 主线程 30 秒无心跳会触发看门狗：写 `logs/ui_watchdog.log` 并退出进程（fail-fast）；长活必须放 worker。

### 3.3 生命周期

```python
def shutdown(api):
    ...  # 停线程/进程/定时器

def register(api):
    api.on_unload(lambda: ...)
```

- reload、更新、禁用、退出前调用 `shutdown(api)`，再跑 `on_unload` 回调；都在主线程/GIL 内；
- 回调里不要碰控件；只做线程/进程/文件/模块清理；
- 动态 import 的 vendor 模块用 `api.register_module` 登记；
- Python 线程不能强杀，`shutdown` 是协作式的；插件必须让 worker 自己退出。

## 4. `api.host`

- `pref_get(section, key, default)` / `pref_set(...)`：写 `xrkit_user.ltx`；
- `data_dir()` / `cache_dir()`：插件自己的持久/可清理目录；
- `run_process(options)`：`program/args/working_dir/on_stdout/on_stderr/should_stop/cancel_wait_ms`；
- `start_process/stop_process/process_alive`：长驻进程，无管道，日志重定向到文件，kill-on-close；
- `http_get` / `http_post`：返回 `ok/status/body/error/bytes/truncated`；阻塞期释放 GIL；回环地址直连；
- `http_download(url_or_urls, path, timeout_sec=300, max_bytes=8GB)`：同步下载，走 `DownloadManager`；多 URL 由管理器探测/回退；
- `http_download_async(url_or_urls, path, workers=4, timeout_sec=300, max_bytes=8GB, prefer_direct=False)`：立即返回 job；与同步下载/宿主更新共用管理器；
- `http_download_status(job)`：`found/finished/ok/cancelled/done/total/error/path/url`；
- `http_cancel(job)`：置取消位；阻塞中的 WinHTTP 最多等到当前超时；分片保留；
- 插件卸载/reload 时，宿主按 owner 自动取消全部异步下载；
- 同步 HTTP 调用必须放 `task_run` worker；UI 线程调用直接拒绝；
- `api.supports("host.http_async")` / `"host.http_download_async"` 可探测能力。

## 5. `when` 条件

- falsy ⇒ 恒真；
- dict ⇒ 字符串键值比较；非字符串值不命中；`None` 表示键不存在；
- 可调用对象 ⇒ 收 dict，真值命中；异常按不命中；
- 其它真值（含裸字符串）恒真。

## 6. 拖放

`ui.drop_box(parent, on_file, placeholder, width)` 接收本机文件；回调当前只取第一个路径。

## 7. 网络与 SQLite

- 发行包带 Python SSL 和 sqlite3，可直接用 `urllib` / `http.client` / `sqlite3`；
- 「工具 → 联网功能」只约束宿主更新，不强制约束插件；需要尊重时读 `api.host.pref_get("network","enabled","1")`；
- 联网放 worker，自设超时/大小上限；
- SQLite 文件放插件目录；不打开不可信库；同一连接不要跨线程。

## 8. 调试

| 手段 | 用法 |
|---|---|
| `xrkit_cli --py-plugins <dir>` | 加载/统计/错误/禁用原因 |
| `xrkit_cli --ui-facade` | 实际暴露的 UI 名字 |
| `logs/log_*.txt` | 宿主日志；`api.log` 写一行 |
| `xrkit_plugin_manager.exe` | 已加载/禁用/更新 |

限制：

- 同进程：崩溃、import 副作用、死循环会影响宿主；
- `PLUGIN_INFO.requires` 缺前置会自动禁用；
- 插件更新是整目录备份+替换，失败回滚；原禁用状态保留。

## 9. 无界面入口

```python
def headless(api, args):
    return {"ok": True, "value": args.get("path", "")}
```

```bat
xrkit_cli --py-plugin-call plugins {"path":"E:\\x"}
```

不得触碰 `api.ui`；返回值会 JSON 序列化。

## 10. 扩展点

- `register_decryptor(check, decrypt)`：check 必须便宜；decrypt 在 worker；明文落临时隔离目录，不写回源；
- `register_format(name, handler)`：声明识别，解析由插件完成；
- `register_compare_mode(spec, compare)`：返回 dict；未知键进 `unhandled_keys`；
- 能力查询：`api.supports("api.register_decryptor")` 等。
