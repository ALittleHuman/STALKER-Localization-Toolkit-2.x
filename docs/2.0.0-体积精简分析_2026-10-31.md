# 2.0.0 体积精简分析（2026-10-31，实测）

## 一、现状（包 BETA.51，实测）

| 项 | 大小 | 占比 |
|---|---|---|
| 包总计 | **260.5 MB** | 100% |
| `bin\ffprobe.exe` | **97.9 MB** | 37.6% |
| `bin\ffmpeg.exe` | **83.6 MB** | 32.1% |
| ffmpeg + ffprobe 合计 | **181.5 MB** | **69.7%** |
| python\ | 23.3 MB | 8.9% |
| tools\（含 vendored fontTools 16.6 MB） | 16.6 MB | 6.4% |
| 根目录（xrkit_app 6.4 + Qt 等） | 35.7 MB | 13.7% |

当前 ffmpeg 来源：**gyan.dev 7.1 essentials static**
（`ffmpeg version 7.1-essentials_build-www.gyan.dev`，gcc 14.2 static）。
必要能力（代码里实际用到）：

- 编码器：`libtheora`（视频）、`libvorbis`（音频）、`libxvid`/`mpeg4`（回退）
- 复用器：`ogg`（OGM 容器）
- 解复用/解码：`avi` / `ogg`（matroska 备用），mpeg4/theora/vorbis/pcm/mp3 等
- 版本限制：**必须 7.x**（8.x 的 libtheora 对 STALKER OGM 有缺陷，package.ps1 与下载脚本都钉死）

## 二、已实测的候选（不采纳/采纳）

| 方案 | 实测体积 | 结论 |
|---|---|---|
| 官方 7.1 **shared**（BtbN gpl-shared 7.1.5，实测解包） | exe+DLL = **151.8 MB**（不含 ffplay） | ✗ 只省 ~30 MB，还多 9 个 DLL；`avcodec-61.dll` 89.6 MB 是主因 |
| 官方 7.1 essentials **static**（现状） | 181.5 MB | 基线 |
| **自建最小 static / shared（7.1.5）** | 预估 **15–25 MB**（static 两枚约 25，shared 约 16） | ★ 推荐，需 MSYS2 工具链 |
| **砍掉 ffprobe**（探测改用 `ffmpeg -i` 文本解析） | **−97.9 MB** → 包 162.6 MB | 可行，但要改 `parse_ffprobe_json` + 重生成 golden |
| UPX 压缩 | 预估 −120 MB | ✗ 杀软误报（本仓已有 360 申诉史），不做 |

## 三、推荐路线

### 第一步（立刻，无需构建）：砍 ffprobe

- `FfmpegLocator` 允许 `has_probe=false`；探测改走 `ffmpeg -hide_banner -i <file>` 文本解析；
- `parse_ffprobe_json` 保留（有外部 ffprobe 时仍用它，goldens 不废），新增 `parse_ffmpeg_stderr_info` 兜底；
- 预期：包 260.5 → **162.6 MB**（省 97.9 MB）。

### 第二步（大头）：自建最小 7.1.5

MSYS2 + mingw-w64 + nasm，configure 收窄到上面那组能力，产物目标：

```
--disable-everything --disable-doc --disable-network --disable-autodetect \\
--enable-gpl --enable-libtheora --enable-libvorbis --enable-libxvid \\
--enable-demuxer=mov,avi,ogg,matroska --enable-muxer=ogg \\
--enable-decoder=mpeg4,theora,vorbis,pcm_s16le,pcm_s24le,mp3,ac3,aac \\
--enable-encoder=libtheora,libvorbis,libxvid \\
--enable-filter=scale,fps,format,aresample,anull,crop,null \\
--enable-protocol=file --enable-swresample --enable-swscale
```

- 预期：包 162.6 → **约 105 MB**；两步合计省 ~155 MB（−60%）；
- 代价：机器时间约 1–2 小时（装 MSYS2 + 编 libogg/libvorbis/libtheora/libxvid + ffmpeg），
  且产物必须做真机验证（OGM 输出能被游戏读、theora 版本行为一致）。

### 第三步（可选）：非 ffmpeg 部分

- `tools\fontlib\fontTools` 16.6 MB 全量 vendored —— 只用 `TTFont`/`glyf`/`cmap`/`hmtx`，裁到所需模块可省 ~10 MB；
- `python\` 23.3 MB 是文档/测试/IDLE 一并带的完整发行；可裁 `test/`、`pydoc_data/`、`tcl/`，约省 6–8 MB。

## 六、模块表更正（用户 2026-11-01 复核：漏了 mov/H.264/HEVC/AAC）

源过滤器里明确有 `*.mp4` / `*.mov` / `*.m4v`，只编 avi/ogg 会让 MP4/MOV 直接失败。
最小 configure 至少还要：

```
--enable-demuxer=mov,avi,ogg,matroska
--enable-decoder=h264,hevc,mpeg4,msmpeg4v3,mjpeg,aac,mp3,ac3,eac3,pcm_s16le,pcm_s24le,theora,vorbis
--enable-encoder=libtheora,libvorbis,libxvid,mpeg4
--enable-parser=h264,hevc,mpeg4video,mjpeg,aac,mpegaudio,ac3,eac3,theora,vorbis
--enable-filter=scale,fps,format,aresample,aformat
```

另：libxvid 是 GPL —— 保留就要接受许可证；不保留则用原生 `mpeg4` 回退（代码里已有回退链）。
目标不变：**static 单枚 20–30 MB**，不再编 ffprobe。
