# 2.0.0 界面重构口径（排版 + 配色）—— 待你过目，随后按此实施

> 触发：用户 2026-09-27 原话 **"排版完全重新设计。现在的还是不行。配色也改一下。"**
> 边界（沿用你先前授权）：**不改六页划分**；重构必须继续过门禁；提交信息里说清"为什么动"。
> 铁律：**判据要能在真程序里量、能进闸门、能判红**；看截图不算判据。

## 一、先把"还是不行"拆成可改的点（诊断）

| # | 现状（截图可见） | 为什么难看 |
|---|---|---|
| 1 | 页面里 标题 / 说明 / 操作栏 / 内容区**是同一个平面** | 没有视觉层次，眼睛找不到"从哪开始看" |
| 2 | 内容区是**裸列表**（`QListWidget` / `VirtualList` 直接铺满） | 没有卡片/分组边界，空白区像坏掉 |
| 3 | 左侧六页是**裸列表** | 没有"当前在哪一页"的强提示（只有默认蓝底一行） |
| 4 | 日志区是**裸等宽文本块** | 与主内容同权重，抢视线 |
| 5 | 控件是**默认 Qt 观感**（按钮/下拉/勾选/表头都不统一） | 像未完成品 |
| 6 | 配色**单一深灰**、无强调色、无 hover/pressed/disabled 区分 | 分不清"可点/不可点/已选" |
| 7 | 间距**随手给**（4/6/8 混用） | 节奏不齐，显廉价 |

## 二、配色口径（重做令牌，暗/亮两套）

**角色（新增/明确）**：`app_bg` / `panel_bg` / `panel_alt_bg` / `card_bg` / `border` / `border_strong` /
`text_primary` / `text_secondary` / `text_disabled` / `accent` / `accent_hover` / `accent_pressed` /
`danger` / `success` / `selection_bg` / `nav_bg` / `nav_selected_bg` / `log_bg`。

**取值基调（我定，供你否决；以暗色为主，亮色同步）**：
- 暗色：`app_bg #1e2124`、`panel_bg #26292d`、`card_bg #2b2f33`、`border #3a3f45`、`text_primary #e8eaed`、
  `text_secondary #a8b0b8`、`accent #4c9ed9`（选中/主按钮）、`danger #d9534f`、`success #5cb85c`、
  `nav_selected_bg #31363b` + 左侧 **3px accent 条**；
- 亮色：`app_bg #f4f5f7`、`panel_bg #ffffff`、`card_bg #ffffff`、`border #d8dce1`、`text_primary #1f2328`、
  `text_secondary #5a636b`、`accent #2b6cb0` 等。
- **强调色只用于三处**：当前导航项、主操作按钮、"正在跑"的进度/状态；别到处刷蓝（这是现在最大的观感病）。

## 三、排版口径（统一骨架 + 间距节奏）

1. **页面骨架**（六页统一，`PageBase` 改造）：
   ```
   ┌ 页标题（18pt 粗）  副标题：一句话说明当前页能干什么（12pt，secondary 色）
   ├ 内容卡片（card_bg + 1px border + 圆角 6 + 内边距 12）：本页的主内容（列表/树/表单）
   └ 操作栏（贴底、右对齐；主按钮=accent 实心，次按钮=描边） 
   ```
2. **间距节奏固定 4/8/12/16**（不再随手给）；卡片间距 12；卡片内边距 12；页边距 12。
3. **左侧导航**（Hub）：宽 220px、项高 32px、当前项 `nav_selected_bg` + 3px accent 左条、hover 用 `panel_alt_bg`。
4. **日志面板**：加**标题栏**（"日志"+「清空」小按钮），背景用 `log_bg`（比卡片更深/更浅一级），
   高度上限沿用 **≤200px / ≤窗口高 30%**。
5. **buildGUI** 用同一套骨架与配色（表单/构建史/日志都按卡片化 + 同一强调色）。

## 四、判据（都要进闸门、能判红）

1. **颜色令牌断言**（扩 `--themecheck`）：
   - 每个角色在**暗/亮两套里都存在且非空**；
   - `text_primary` 对 `card_bg` 的对比度 **≥ 4.5**、`text_secondary` **≥ 3.0**（按 WCAG 相对亮度算）；
   - `accent` 与 `app_bg` **不相等**且亮度差 ≥ 25%（防止"强调色看不出来"）；
   - `nav_selected_bg` ≠ `nav_bg`（防止"当前页看不出来"）。
2. **几何断言**（`SHELL-SMOKE` / `--layout-report`）：
   - 页标题存在且高度 > 0、字号比正文大（用 `font().pointSizeF()` 断言差值 ≥ 2）；
   - 内容卡片高度 ≥ 页面高的 **60%**；操作栏**贴底**（底部间距 ≤ 8px）；
   - 导航项高 32±2、当前项有 accent 左条（用 QSS 属性或自绘标记断言）；
   - 间距：页边距/卡片间距落在 **{4,8,12,16}** 集合内。
3. **能红的证明**：把任一角色改回"与背景相同"或"删掉 accent 左条"⇒ 上述断言必须变红（实施时逐个注入验证）。

## 五、实施顺序（每步一条进度，不打断）

1. 令牌表重做（含生成器与 `--check`）→ 颜色断言进闸门；
2. `QSS` 重写（控件统一：按钮/下拉/输入/列表/滚动条/表头/勾选）；
3. `PageBase` 骨架改造（标题+副标题+卡片+贴底操作栏）→ 几何断言；
4. Hub 左侧导航（选中态 + accent 条）；
5. 日志面板标题栏 + 上限复核；
6. buildGUI 同语言（含 `--layout-report` 扩展）；
7. `run_ci.py --release` + `scripts/package.ps1` 重打包更新指纹 + 交接区材料。
