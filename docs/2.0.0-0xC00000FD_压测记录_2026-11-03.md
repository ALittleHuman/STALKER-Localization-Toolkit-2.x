# 0xC00000FD（栈溢出）压测记录 · 2026-11-03

**口径**：不结案。只有抓到调用栈才算归因；"没复现"只写"低频未复现"。

## 本轮做了什么

- `SHELL-SMOKE` 连跑 **20 轮**（每轮独立进程，`Start-Process -Wait` 取退出码）；
- 记录文件：`build/logs/soak_smoke_20.log`（`round,exit`）。

## 结果

```
20/20 轮 exit=0，checks=959 failed=0
0xC00000FD 未复现
```

## 没做的（以及为什么）

- `--fast` 全量循环：单轮约 12 分钟，20 轮 ≈ 4 小时，本轮窗口不够；
- `procdump -e -ma -w`：本机未装 procdump（sysinternals），且抓 dump 需要复现窗口；
- ⇒ **仍记为未闭合**；下次复现按 `procdump -e -ma -w xrkit_app.exe` 抓栈，`!analyze -v` 看调用栈。

## 相关但不同的一件事（已修）

`0xC0000409`（fail-fast，`--py-plugins` 带 list 元数据时）已归因并修复：
根因是 C++ 在 GIL 块里迭代 `py::object` 拼列表，改成 Python 侧拼接后消失（BETA.96）。
**它不是** 0xC00000FD 的证据，两者不可互相证明。
