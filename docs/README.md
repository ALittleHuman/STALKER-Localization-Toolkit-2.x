# 文档索引

## 按角色读

| 你是 | 先读 | 再读 |
|---|---|---|
| **普通用户** | 根目录 `README.md` | `用户手册.md`（五个页面怎么用）→ `已知问题与边界.md` |
| **脚本/批处理用户** | `CLI参考.md` | `用户手册.md` 的"文件系统""编码转换"两节 |
| **插件作者** | `插件开发.md` | `CLI参考.md` 的 `--py-plugin-call`、`--py-plugins` |
| **构建/发版** | `构建与发版.md` | 根 `README.md` §六 |

## 文档清单

| 文件 | 内容 |
|---|---|
| `用户手册.md` | 五个内置页的逐项操作、典型流程、常见错误与处置 |

## 写作约定

1. **只写当前行为**：路径、按钮名、退出码、参数必须与当前代码一致；不确定的写进
   `已知问题与边界.md` 的对应小节，不写成肯定句。
2. **面向用户与面向开发者分开**：用户手册不出现内部术语（`stk_ui`、`facade`、`gate`）；
   插件/构建文档可以出现，但先解释一句。
3. **数字以程序为准**：页数、动作数这类数字用"以界面/`--actions` 为准"的表述，
   不写死会随版本变化的常量。
4. **示例可直接执行**：占位符用 `<...>` 标出，其余保持原样。
