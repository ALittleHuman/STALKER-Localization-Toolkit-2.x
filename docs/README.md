# 文档索引

本目录记录 STALKER 汉化工具集 2.0 的设计口径、操作说明与历史复盘。

## 阅读顺序

1. `2.0.0-外壳规格.md`：窗口、页面、菜单、任务壳；
2. `2.0.0-字库模块规格.md`：字符集、字体、DDS/INI、IXR；
3. `2.0.0-文本模块规格.md`：编码、提取、语言包；
4. `2.0.0-打包与发版规格.md`：构建、包结构、自检、发布；
5. `2.0.0-工作区审计_2026-11-13.md`：当前修复状态与开放风险；
6. `2.0.0-已知问题与范围_封测.md`：可用范围与发布边界。

## 口径

- 代码、测试、实际包是事实来源；文档与它们冲突时，以代码为准。
- 历史复盘保留“历史”属性，不把旧版本行为写成现状。
- 版本号以 `version.json` / `version.h` / `.rc` 为准。
- 当前源码基线：`2.0.0 BETA.244` 之后工作区。
