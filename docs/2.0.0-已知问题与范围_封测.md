## 已知问题（5 条）

1. **崩溃码 `0xC00000FD` / `0xC0000409` 尚未完全归因。**
   已确认的 `0xC00000FD` 之一是构建期 CMake 整文件正则爆栈（已修），**产品侧若真崩仍按日志查**。
   崩溃后请把 `logs\*_abnormal_exit.txt` 发我。

2. **视频容器只支持**：mp4 / mov / m4v / mkv / webm / avi / ogm（参考用 OGM）。
   ffprobe 已随包移除；码率精度到 kb/s。

3. **无自动安装、无自动更新。**
   帮助菜单保留「打开仓库页」和「检测更新」两个入口；检测更新由宿主内置 HTTP 完成。
   包是解压即用；升级请整目录替换。

4. **字体 A 路线（TTF 合并）只补缺失字形，不追像素一致。**
   工具会把缺的字形合进目标 TTF，保留原字体名/度量；
   **字形风格与发布包不保证逐像素一致**（那是封测后的视觉精修）。

5. **CLI 追更尚未在真实 CoP 相邻版本上验证。**
   `--snapshot / --diff-snapshot / --track` 的管线与合成样本已验；
   真实“上一版 → 这一版”只跑过单份 `gamedata`，**准确率结论待两份样本**。

## 两个容易误判的点（请先看）

- **「XML 对比」默认 stats 只比 ID 集合与文件数，不比文本内容。**
  要追文本改动请切「ID 文本对比」（CLI：`--mode text`）。默认模式下看不到纯文本改动**不是 bug**。
- **追更目前只有 CLI**（`xrkit_cli.exe` 随包）。
  页面等价入口 = 文本工具页的「XML 对比」+「ID 文本对比」模式。

## 怎么给我日志

- 正常退出：日志会按“上次正常退出 ⇒ 重置”的规则清掉，**要留就点「保留本次日志」**；
- 崩溃/强杀：上次那份会自动改名 `*_abnormal_exit.txt` 保留；
- 日志目录：`<解压目录>\logs\`。

## 显式非目标（不是 bug，别改）

### 位图 writer 不消费参照包

`--font-pack --ref <包>` 对**位图**路径无效（按 `builtin` 之外的目录处理时走矢量路径；
位图路径只吃内置模板）。理由：

- 位图段表与 DDS 贴图布局**一一绑定**（每段对应固定的 `ui_font_*` 贴图与 ini），
  喂参照包等于重写 writer；
- IX-Ray 系（36 段）本来就该走矢量路径；位图只服务原版三作（15 段模板）。

⇒ 如果有人把"`--ref` 对位图无效"当 bug 修，会直接破坏位图产物的逐字节对拍。

### GUI 与 CLI 同一入口

`fontpack_page.cpp` 与 `--font-pack` 都只调 `engine::font::build_font_pack()`；
游戏名只决定默认来源（IX-Ray ⇒ 参照包快照）。静态锁：`tests/check_font_pack_single_entry.py`。

### 字形合并判据的分工（别让一条判据承担两件事）

- **⑧ 可复现（同输入同产物）**：同一输入三次合并 sha256 相同；开发树产出与包内产出逐字节相同。
  这条证明的是**确定性**，不证明"与历史发布样本一致"。
- **⑨ 与已发布样本对拍**：需要一份真实发布过的包（相邻版本）才能做 —— 挂在
  「真实 CoP 相邻版本样本验证」这个阻塞项下，**缺样本时不许写成通过**。

### 提取只处理松散文件（2026-11-07 用户口径）

- 「提取文本」**只接受已解包的松散目录**（需含 `gamedata/configs` 或 `configs`，里面有 `scripts/` 或 `gameplay/`）；
- **不代用户解包、不代用户覆盖**：容器（`.db`/`.sqfs`）与加载优先级是用户自己的事（工具搞不清 overlay 顺序，硬做只会出错）；
- 修前「提取文本」调的是 `build_ori_tree`（整树复制 18.8 GB + 多语言覆盖），现改为 `extract_dir`（只抽字面量表）；
- 判据：`ORI-TEXTS`（已有译文不被覆盖 / `--texts-only` 不复制整树 / 源不被改写）+ `XML-EXTRACT-MODE`（页面调 `extract_dir`）。

### 语言包收敛口径（2026-11-07 用户两条）

- **所有语言都收**：`configs/text/<lang>` 里有几种收几种（页面/CLI 都不再钉死 `rus`）；
- **默认不收地图纹理**：`gamedata/textures/map/**` 与 `ui_new_game_map_*` 是汉化交付物里的地图改图，不是语言包通用件；要收请显式 `--include-map`；
- 判据 `LANGPACK-COLLECT`：默认输出 == 参照包去掉 `gamedata/textures/**`（含多语言）+ 逐字节；`--include-map` == 参照包全部 231。

### 语言包收敛：结构规则，无模组特异（2026-11-08）

- 不再硬编码 `gamedata/`、`ixr_addons/`、`textures/map`；只按结构判断：
  任意前缀下的 `configs/text/<lang>/**`、`configs/{fonts,localization}.ltx`、
  与某个 `configs` **同根**的 `fonts/**`；
- 语言名从路径扫出来（默认全收），页面把字面量表复制到**输出树里所有** `configs/text/<lang>`；
- `--include-map` 之类模组特异开关已删除；
- 判据 `LANGPACK-COLLECT`：参照包默认 == 去掉 textures + 逐字节；另加"非 gamedata 前缀"通用性夹具。
