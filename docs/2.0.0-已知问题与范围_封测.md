# 已知问题与范围（当前版）

适用：`2.0.0 BETA.244` 之后工作区。正式发布包以 `dist` 为准。

## 1. 可用范围

内置五页：

- 文件系统；
- 编码转换；
- 文本工具（XML）；
- 视频转换；
- 汉化包生成。

插件页、Python 门面、解密器属于扩展能力，不等同于内置页的稳定性。

## 2. 当前明确未关闭

### 插件注册

`register_decryptor`、`register_format`、`register_compare_mode` 还没有 Python 绑定。Python 插件只能用已绑定的注册点。

### 解密闸门

产品内没有真实的解密器注册者，闸门当前基本放行；加密 SquashFS 的类型判断还可能发生在闸门之前。

### 联网开关

宿主 HTTP 会被「工具 → 联网功能」拦截；插件若自己用 ctypes/其他方式直连网络，不受这条开关约束。

### 崩溃归因

`0xC00000FD`、`0xC0000409` 尚未完全定位。插件与宿主同进程，崩溃归属更难区分。

### 字体选择器 smoke

真实 UI 双击选择正常；smoke 的选择器交互段仍未恢复，包内自检只记录“未覆盖”。

## 3. 更新通道

- 正式版：只升正式版；
- 测试版：可升后续测试，也可升更高正式版；
- 正式版不会被推送测试版；
- 要在正式版上试测试版，只能手动从 GH/其他渠道安装；
- 更新源支持 GitHub API 直连与 `gh-proxy.com`；
- 下载支持 `.part` 断点续传；
- 更新失败由 `xrkit_updater` 回滚。

## 4. 数据安全边界

- 汉化包生成失败不再删除已有 `gamedata`；
- 插件还原在备份不可读时 fail-closed；
- 补丁生成拒绝 `patched/expect` 不等长；
- 源码包/成品包不含用户绝对路径；源码测试夹具和系统字体兜底路径除外。

## 5. 发布前必须做

```text
本机 SHELL-SMOKE failed=0
包内 SHELL-SMOKE failed=0
golden_text_extract PASS
check_audit_p0_guards PASS
```

任何一项未过，不得把包写成“可发布”。
