# 限制与注意事项

本页只写**当前版本的用户可见限制**与规避办法；不涉及版本沿革。

## 1. 路径与编码

- 程序没有声明 UTF-8 代码页，也不支持长路径：
  - 安装目录、输入/输出路径请用**短且全 ASCII** 的路径；
  - 命令行传**中文路径**可能乱码（按 UTF-8 解释 `argv`，系统给的是 ANSI）；
  - 解包遇到 **超过 260 字符**的深层路径会被**整体拒绝**（提示「拒绝落盘：问不出落点的属性（stat 失败）」），不会静默跳过。
  - 规避：解到短根（如 `D:\x\`），必要时用 `subst` 缩短盘符路径。

## 2. 封包（LZHUF）

- 极难压缩的数据可能触发编码失败；此时**可能仍写出"头长度为 0"的包并报成功**。
  - 规避：封包后执行 `xrkit_cli --dump <包>` 验一下；读不出条目就删包重试。
  - 这类包不要直接发布。

## 3. 文本提取

- 图形界面内置五页**不含**文本提取，请用命令行：

```bat
xrkit_cli --extract-text <源目录> <输出目录> [--prefix gs]
```

- **含 `--` 的脚本文本不会被提取**：脚本按 `--` 剥离注释时也会命中字符串内部，
  于是 `"Wait -- do not go"` 这类整条文本被跳过（计入 `notext`，不报错）。
  - 规避：提取后核对 `notext`/`strings`；需要时先把这类文本改成不含 `--` 的写法再提取。
- 脚本侧的全局替换不区分"注释里的同名字面量"，若同一句文本出现在注释里，注释也会被改写。

## 4. 插件

- 插件 API 为实验性；`PLUGIN_API` 是 Python 插件 API 的**契约版本**（当前 2；API 1 仍兼容），不是二进制 ABI。
  支持顶层 `*.py` 与 `<name>/plugin.py`（或 `__init__.py`）两种形态。
  目录插件按**包**加载（`from . import helper` 可用）；模块名 = 入口名（非标识符会归一化，
  如 `00_x` → `_00_x`）。跨插件 import 只允许在 `PLUGIN_INFO` 赋值之后，且目标必须写进
  `PLUGIN_INFO.depends`（未声明/目标被禁用/版本不符 ⇒ `ModuleNotFoundError`）；
  运行时（按钮回调、worker）禁止跨插件 import，请用 `api.services.call`。
  **守卫不是沙箱**：同进程下仍可读文件、`ctypes` 加载 DLL、绕过 `import` 直接取 `sys.modules`。
- 插件可联网、可用标准库 `sqlite3`（发行包随带 Python SSL 与 sqlite3）；「工具 → 联网功能」开关
  **不强制约束插件**，只约束宿主自身的检查更新与下载。
- 插件与宿主**同进程**：崩溃、死循环、`import` 期副作用都会影响宿主（无隔离、无超时）。
- 随包的 `plugins\*_page.py` 是 API 样例，**不承诺生产可用**：
  - `video_page.py`：转码起不来（编码器扫描被线程闸门拒绝）、手改路径可能转错文件；
  - `toolchain_page.py`：产物目录层级不适合直接装进游戏；
  - `convert_page.py`：可作为任务壳/暂停门写法参考。
- 官方发行包默认 `plugins\` 顶层为空（避免样例页抢内置页）；你自行安装的第三方插件会出现在这里。

## 5. 视频转换

- ffmpeg 只认两处：`xrkit_user.ltx` 的 `[ffmpeg] path`/`probe`，或程序目录/`bin`；**不搜 PATH**。
- 只接受 **7.x**（8.x 的 theora 对 STALKER OGM 有 bug，页面会拒绝）。
- 发行包**不带 ffprobe**：缺 ffprobe 时自动降级 `ffmpeg -i`，页面会显示"已降级"。
- 输出 == 源/参考 ⇒ 直接拒绝；输出已存在 ⇒ 问一次。

## 6. 编码转换

- **单文件 + 原地 + 勾备份**时，备份路径退化为 `<文件>\backup\..bak`，会失败。
  建议单文件转换时填写输出目录，或转换前手动备份。
- **输出目录 == 源目录**时按原地覆盖处理且不备份，操作前请确认。
- 自动判定不确定会弹确认（判定/理由/标记/置信度/文件名）；答否即跳过。

## 7. 汉化包生成

- 缺字默认只警告；严格失败用 `--on-missing fail`。
- 输出目录不要直接指游戏根：成功会覆盖 `gamedata` 下同名文件（失败会回滚）。
- 重新生成到同一输出目录时，**上一次生成的旧字库文件（不同字号/后缀）不会被自动清理**；
  需要干净产物请换新目录。
- `字号+N`（位图字库）与 IX-Ray 矢量 `--font-size-patch`（只改 `fonts.ltx`）是两套机制。
- 文件名含 cp1251 表示不了的字符时会改写成 `?`，逐条列在日志（"名字改写"台账）。

## 8. 更新

- 正式版只查正式 Release；测试版（BETA/RC）在 GitHub 上必须以 **Prerelease** 发布，可升后续测试版或更高正式版；正式版不会被推测试版。
- 若 Release 的 `tag_name` 不是 `x.y.z` 开头、后缀不是 `.n` 或 `alpha/beta/rc.n`（分隔符可为 `.`/`-`/`_`/空格），
  检查更新会静默失败（手动检查时显示"没有当前通道可用的 Release"）。
- 一个 Release 含多个 `.zip` 资产时，只有第一个包的 sha256 会被用于校验，可能拒绝后续包。
- 启动后 2 秒自动检查更新；网络慢时窗口可能在这段时间**无响应**（最长约 20 秒）。
  可通过「工具 → 联网功能」关闭，或用 `--no-auto-update` 启动。

## 9. 门禁与自检（贡献者）

- `--smoke` 会读写真实的 `xrkit_user.ltx`（有备份/逐字节还原），跑前请先备份该文件。
- 部分门禁判据需要仓库外的 1.x 源码（`XRKIT_TOOLKIT_1X`）；缺件记 SKIP，`--release` 下算 FAIL。
- 手工构建必须设置 `XRKIT_PYTHON`；未设置时可能量不到 `/showIncludes` 前缀，
  导致"改头文件不重编"。

## 10. 遇到问题时

- 附 `logs\log_*.txt`（界面与引擎日志同源）；
- 说明操作步骤、输入样本类型与输出目录；
- 涉及封包/解包的异常，附 `xrkit_cli --dump` 的结果。
