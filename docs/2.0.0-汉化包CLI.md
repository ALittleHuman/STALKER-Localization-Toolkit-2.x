# 汉化包 CLI 推荐流程（BETA.240+）

## 一条命令（默认字体 + JSGME + 字号补丁）

```bat
xrkit_cli.exe --font-pack ^
  --ref builtin ^
  --text-root "E:\...\2.汉化" ^
  --out "E:\...\更新" ^
  --langs rus ^
  --jsgme --jsgme-category "汉化" --jsgme-name "2.汉化" ^
  --patch-offsets 7
```

说明：

- `--font` 可省略；CLI 自动找 `NotoSansSC-VF.ttf`，找不到再回退微软雅黑。
- `--text-root` 可以是包根、`gamedata` 根、`gamedata/configs/text/rus`，或文本目录本身。
  包根模式会自动把 `gamedata/scripts` 和 `gamedata/configs/gameplay` 带进成品。
- `--patch-offsets 7`：base 永远是标准字号，另出 `字号+7` 补丁 MOD。
- `--jsgme` 与 `--patch-offsets` 可以同时用。

## 成品结构

```text
<out>/
├── JSGME.exe
├── JSGME.lng
└── MODS/
    └── <分类>/
        ├── <名>/                     ← base，标准字号
        │   └── gamedata/{configs,scripts,textures}
        └── <名> 字号+7/              ← 只含 textures/ui 的补丁
            └── gamedata/textures/ui
```

## 校验

```text
FONTPACK ok ... xml=N scripts=N gameplay=N warnings=0
FONTPACK patch offset=7 ...
FONTPACK jsgme mod=MODS/...
FONTPACK jsgme patch=MODS/... 字号+7
```

缺字：

- 语料里真实用到的字缺失 ⇒ 默认不出包（`--on-missing warn` 可继续）；
- 仅“基线西里尔”缺失、语料没用到 ⇒ 不再刷警告；
- 要强制完整西里尔：`--require-full-cyrillic`。

## 旧命令为什么错

| 旧做法 | 问题 |
|---|---|
| `--text-root` 指向包根 | 旧版 xml=0，scripts/gameplay 也不带 |
| `--offset 7` | 把 +7 直接烤进 base，没有“默认 + 补丁” |
| `--jsgme` 不带 `--patch-offsets` | 只有 base，没有字号补丁 |
| `--patch-offsets` + `--jsgme` | 旧版直接报“暂不支持” |
| 显式 `--font msyh.ttc` | 绕过默认 NotoSansSC |
