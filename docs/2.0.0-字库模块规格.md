# 2.0.0 字库模块规格（M1-7，第一版：判据与管线）

> **判据（用户 C3 口径）**：**实现方式可以改变，生成产物要保持原样** ⇒ 与 1.x 的同输入产物
> **逐字节一致**（`ui_font_NN.dds` + `ui_font_NN.ini`），外加 1.x 已有的**几何判据**（11 组）。
> 参照实现的已知难点见 §5（R2），差异要**逐条报账交用户裁决**，不许悄悄放宽。

## 1. 管线（`font_pack.render_font` 逐句对照）

| # | 步骤 | 是否影响字节 | 备注 |
|---|---|---|---|
| 1 | `fit_render_size(font, size, x2)`：候选字号 `size..size+13` 取最大的、对样本每字满足 `墨迹高 ≤ cell−4` 且 `墨迹宽 ≤ min(推进宽, cell)` | 间接（决定 glyph 尺寸） | 只用 **bbox** ⇒ 只需 bbox 一致，不需像素一致 |
| 2 | `font.getmetrics()` → `vshift = max(0, cell_h − (asc+desc)//S)` | 是（位置） | asc/desc 需与 Pillow 一致 |
| 3 | 画布：`tex_w` 1024→2048→4096 保证放下；`max_y = rows*cell_h`、`tex_h` = ≥max_y 的 2 幂 | 是 | ★ 历史坑：`need = max_y`（不是 `max_y−1`） |
| 4 | 逐字符：`bbox=getbbox`、`mask=getmask(mode="L")`、`mb=mask.getbbox()`；缺字形 → `st_fallback` 用繁体字形（**码位不变**） | 是 | 缺字形判定 `mb is None` |
| 5 | 宽度口径顺序：`rect_w_for(size,ch)`（表/方块兜底）→ 标点 `punct_box_px` → `clamp_box_to_ink`（框不得窄于墨迹）→ **封顶 `cell`** → `ink_draw_w` | 是（写进 ini 的 x2） | 逐条照抄，不许"优化"顺序 |
| 6 | 裁剪 `mask → crop(mb)`；`S=2` 时 `resize((gw,gh), LANCZOS)` | 是 | **S=1 档完全不做重采样** |
| 7 | 垂直：`top = bbox[1]//S + vshift`；装不下先整体上移；再放不下才裁进行带 | 是 | 裁的是行带外不可见像素 |
| 8 | 水平：`x = col*cell + (cell−rw0)//2 + left0 − pl`，`paste(x+pl, y+top)` | 是 | `left0 = mb[0]//S`（设计内缩） |
| 9 | ini 行：`f"{ord(ch):05d}= {x}, {y}, {x+rw}, {y+cell_h}"`，首行 `[mb_symbol_coords]`+`height=cell` | 是 | 完全确定 |
| 10 | 像素：`canvas.tobytes()`；`8888` 每字节 → `(v,v,v,v)`；`A8` 原样 | 是 | |
| 11 | DDS 头（legacy，128 B，无 DX10 头）：`write_dds` 的那串常量 | 是 | 直接照抄 |

## 2. 只有两处"技术难点"

### 2.1 栅格一致 —— **已验证可行（2026-09-24）**

探针 `tests/golden_font_raster.py`（门禁第 [16] 步）：`msyh.ttf` 的 58 个样本字符 × 字号
11/13/15/17，我们的 FreeType 栅格与 Pillow `getmask(mode="L")` **逐字节一致**。

复刻口径（实测得到，写进代码别猜）：

```
mask 画布：宽 = advance 像素（advance_26_6 // 64）
           高 = max(墨迹行数, bitmap_top)
墨迹落在  (bitmap_left, 0)
```
- FreeType 调用：`FT_Set_Pixel_Sizes(face, 0, size)` + `FT_Load_Glyph(FT_LOAD_DEFAULT)`
  + `FT_Render_Glyph(FT_RENDER_MODE_NORMAL)`（= Pillow 的默认路径）；
- `mask.getbbox()` **会裁掉首尾全零的行/列** —— 1.x 注释里的"设计内缩 `mb[0]`"就是
  `bitmap_left`（**不是** `font.getbbox` 的 x0，后者对全角标点恒为 0）；
- 边界实测：'你' 的 FreeType 位图末行全零，Pillow 的 `getbbox()` 因此少一行 ——
  这是 bbox 语义，不是像素差异（逐字节比位图本身就一致）。

### 2.2 Pillow 的 LANCZOS（x2 档 16/17/18）

只在 `S=2` 时触发（`glyph.resize((gw,gh), Image.LANCZOS)`）。要复刻 Pillow `Resample.c` 的
可分离滤波器（`precompute_coeffs` + 定点累加 + 边界裁剪）：先取 Pillow 源码做参照
（PyPI sdist 的 `src/libImaging/Resample.c`），实现后逐像素对拍。
**S=1 档（11/13/15）没有这一步**，所以可以先出字节一致的产物。

## 3. 数据表与字符集

- `extract_chars(xml_dir)`：从**译文 XML** 收集字符集（含 `REQUIRED_CHARS`/`ASCII_CHARS`/
  西里尔块与 `LOST_CYRILLIC`/`ANSI_BRIDGE`/`FONTGEN_EXTRA` 那几组补集），顺序即写进图集的槽位顺序。
- `ADV_TABLES`（推进宽）与 `ST_FALLBACK`（简→繁）用生成器转成 `.inc` 常量，`--check` 锁住
  "与 1.x 仓库里的 JSON 一致"（`tools/gen_font_tables.py`）。
- `fonts.ltx` 模板（245 行）与 `build_package` 的产物布局照抄；`GAMES` 决定 `fmt`（8888/A8）。

| ⑤ x2 档 | LANCZOS 复刻（16/17/18） | 同上；差异逐条报账 | 待做 |

## 5. 风险与报账口径（R2）

- 若栅格或 LANCZOS 最终仍有像素差：**先按几何判据（11 组）全部达标**，再把差异
  （位置 × 判据 × 实测值 × 成因）逐条列出交用户裁决；**绝不在判据上偷偷放宽**。
- `S=1` 档先出结果（无重采样），能把"栅格一致性"单独验证干净；x2 档单独排期。
