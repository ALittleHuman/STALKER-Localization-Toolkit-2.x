# Ограничения и важные замечания

Здесь перечислены только видимые пользователю ограничения текущей версии и способы их обхода.

## 1. Пути и кодировки

- CLI и GUI (включая сборщик, менеджер плагинов и updater) объявляют `activeCodePage=UTF-8` + `longPathAware`;
- чтение, упаковка и листинг путей с китайскими/кириллическими символами проверены на практике;
- пути длиннее 260 символов всё равно зависят от системного `EnableLongPaths`; при превышении путь указывается явно, молчаливого пропуска нет.

## 2. Упаковка (LZHUF)

- очень плохо сжимаемые данные могут вызвать ошибку кодирования («длина заголовка 0»);
- после упаковки автоматически выполняется обратное чтение: неразборчивый результат или несовпадение числа записей — ошибка;
- для важных пакетов всё равно рекомендуется `xrkit_cli --dump <пакет>`.

## 3. Извлечение текста

- В GUI: «Работа с текстом» → «Извлечь текст»; в CLI: `--extract-text`; реализация движка одна. В CLI источником может быть сам `scripts`/`gameplay` или корень игры/addons (поддеревья находятся автоматически, относительное дерево сохраняется; таблицы попадают в `gamedata/configs/text/<lang>/`, ID между таблицами не пересекаются);
- строки скриптов с `--` могут быть пропущены логикой удаления комментариев и учтены как `notext`, без ошибки;
- глобальная замена в скриптах не различает одинаковые литералы в комментариях; комментарии тоже могут быть изменены.

## 4. Плагины

- API экспериментальный; `PLUGIN_API=2` (совместим с 1), это не бинарный ABI;
- поддерживаются верхнеуровневые `.py` и `<name>/plugin.py`/`__init__.py`; каталог загружается как пакет;
- межплагинный import должен объявляться в `PLUGIN_INFO.depends`; в runtime-колбэках он запрещён, используйте `api.services.call`;
- защита не является песочницей: в том же процессе плагин может читать файлы и загружать DLL через `ctypes`;
- плагины могут использовать сеть и sqlite3; «Инструменты → Сеть» не является жёстким ограничением для плагинов;
- один процесс: падение/побочные эффекты import влияют на хост; если главный поток UI не подаёт heartbeat 30 секунд, пишется `logs/ui_watchdog.log` и процесс завершается (fail-fast, без горячего восстановления); долгие операции — в worker `task_run`;
- в официальном архиве верхний уровень `plugins\` пуст; совместимость сторонних плагинов обеспечивает их автор.

## 5. Видеоконвертер

- ffmpeg ищется только в двух местах: `[ffmpeg] path/probe` в `xrkit_user.ltx` или каталог программы/`bin`; PATH не используется;
- поддерживается только 7.x; в 8.x есть ошибка theora для OGM STALKER;
- ffprobe в архив не входит; при отсутствии используется `ffmpeg -i`;
- если выходной файл совпадает с исходным/эталонным — отказ; при существующем выходном файле один вопрос.

## 6. Планируемые ограничения

Модульные шрифты (шрифт/выбор символов/предпросмотр по секциям) и бинарные патчи движка вроде OGSR **не входят в 2.0.0**; черновик — в `路线图.md`. В 2.0.0 действует текущая генерация одного шрифта с предупреждениями.

## 7. Перекодировка

- при одиночном файле + на месте + включённой резервной копии путь копии может деградировать; лучше указать каталог вывода или сделать копию вручную;
- если каталог вывода совпадает с исходным, выполняется перезапись на месте без резервной копии;
- при неоднозначном автоопределении появляется диалог; ответ «Нет» пропускает файл.

## 8. Сборка пакета локализации

- два этапа: сканирование и генерация; версия игры определяется по эталонному пакету (`config`⇒SoC; `configs`+8888⇒ClS; +A8⇒CoP; только TTF⇒IXR);
- bitmap-from-ref сохраняет все секции; при нестандартном имени текстуры имя генерируется по номеру секции, ссылки переписываются;
- участвуют все секции шрифтов, включая пользовательские; пропускаются только базовые HUD/STAT;
- `--suffix` — это `font_prefix` в `localization.ltx`, он не пишется в `fonts.ltx`;
- вариативные шрифты инстанцируются по оси `wght`; в интерфейсе есть список и предпросмотр. Статические шрифты игнорируют насыщенность; `--font-weight` поддерживает 100–900. В векторном IX-Ray перерисовка по wght не выполняется, параметр отключается;
- один атлас не больше 8192; для 50px/крупного набора атлас принудительно расширяется до 8192×4096, при превышении — ошибка, без многстраничности и автоуменьшения;
- векторный IX-Ray пишет `FontAtlasSize=8192` в `engine_external.ltx`;
- NBSP больше не считается обрезаемым пробелом;
- при отсутствии глифов по умолчанию только предупреждение; строгий отказ — `--on-missing fail`;
- не указывайте в качестве вывода корень игры; при успехе будут перезаписаны одноимённые файлы в `gamedata`;
- повторная сборка в тот же каталог удаляет шрифты, созданные в прошлый раз, но не созданные сейчас (`stale_removed=`);
- bitmap «Размер+N» и IX-Ray `--font-size-patch` — разные механизмы.

## 9. Обновление и загрузка

- стабильные версии проверяют только обычный Release; BETA/RC должны публиковаться как Prerelease;
- если в Release несколько zip, asset выбирается по build и к нему подбирается digest;
- загрузка обновления идёт через единый `DownloadManager`: `.part.N` + `.segments`, поддержка отмены/докачки;
- во время загрузки доступна «Отменить загрузку»; после отмены частичные файлы сохраняются; закрытие окна также отменяет загрузку;
- после загрузки программа спрашивает о перезапуске; при отказе установка произойдёт при следующем запуске;
- npm — необязательный канал: версия модели C преобразуется в `x.y.z-<build>`; BETA.269 загружена в npm, BETA.270 пока не опубликована, клиент откатывается на GitHub;
- «Инструменты → Проверять обновления» / «Инструменты → Сеть» / `--no-auto-update` отключают соответствующее поведение.

## 10. smoke и CI

- `xrkit_smoke.exe` существует отдельно и в релизный пакет не входит;
- `--smoke` не является командой приложения/CLI;
- smoke читает и записывает настоящий `xrkit_user.ltx` (с резервной копией/восстановлением); перед запуском сделайте копию;
- часть проверок требует внешних исходников 1.x; при отсутствии ставится SKIP, в release-режиме это FAIL;
- при ручной сборке необходимо задать `XRKIT_PYTHON`.

## 11. Обратная связь

Приложите `logs\log_*.txt`, шаги, тип входного образца и каталог вывода; для ошибок упаковки/распаковки — результат `xrkit_cli --dump`.
