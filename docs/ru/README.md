# STALKER Toolkit локализации 2.0 (xrkit)

Инструмент для просмотра ресурсов, распаковки, извлечения текста и сборки пакетов локализации для игр на X-Ray (SoC / Clear Sky / CoP / IX-Ray).

- Язык интерфейса: «Инструменты → Язык интерфейса» или `--lang ru`; при отсутствии перевода — китайский.
- Текущая версия исходников: `2.0.0.530 (BETA.270)`
- Среда: Windows 10/11 x64; в архив уже входят Qt6 и Python 3.14, **системный Python не нужен**
- Инструмент пишет только в выбранный вами каталог вывода, `logs\` и свой `xrkit_user.ltx`; он не устанавливает и не изменяет файлы игры

---

## 1. Возможности

| Возможность | Вход | Описание |
|---|---|---|
| Чтение/запись DB шести форматов и SquashFS | Страница «Файловая система» / `xrkit_cli --dump` | Дерево распаковки, loose-слои, проверка длинных путей и ссылок |
| Определение кодировки и пакетная перекодировка | Страница «Перекодировка» | cp1251 / cp1252 / GB18030 / Big5 / Shift-JIS / EUC-KR / UTF-16/32; журнал сканирования, резервные копии и восстановление |
| Извлечение текста | Страница «Работа с текстом» (режим «Извлечь текст») / `xrkit_cli --extract-text` | Из `configs/gameplay`, `scripts`, `.ltx`; можно указать корень игры или addons — относительное дерево сохраняется, таблицы попадают в `configs/text/<lang>/` |
| Сверка XML | Страница «Работа с текстом» | Сравнение каталогов A/B (статистика / текст), экспорт CSV/XLSX, копирование различающихся ID |
| Видео в OGM | Страница «Видеоконвертер» | Параметры берутся из эталонного OGM; ffmpeg ищется только в двух местах |
| Сборка пакета локализации | Страница «Сборка пакета локализации» / `--font-pack` | Стандартные шрифты, патчи размера, JSGME-раскладка, векторные шрифты IX-Ray |
| Плагины | `plugins/` | Python-плагины могут добавлять страницы, меню, команды, режимы сравнения, дешифраторы и форматы пакетов |

## 2. Установка и запуск

1. Распакуйте архив в любой каталог (лучше в короткий путь; длинные пути — см. §7).
2. Запустите `xrkit_app.exe`; для командной строки используйте `xrkit_cli.exe`.
3. Настройки хранятся в `xrkit_user.ltx` рядом с программой (файл создаётся при первом изменении; удалите его, чтобы вернуть значения по умолчанию).
4. Журналы находятся в `logs\log_*.txt`; прикладывайте их к сообщению о проблеме.
5. Коды возврата CLI: 0 — успех; 1 — ошибка; 3 — действие не выполнено (неверные аргументы, защита записи или требуется подтверждение — читайте строку с причиной).

```text
xrkit_app.exe              графический интерфейс (без smoke)
xrkit_cli.exe              командная строка
xrkit_plugin_manager.exe   менеджер плагинов
xrkit_updater.exe          обновление программы (отдельный процесс, без сети)
xrkit_smoke.exe            офскрин-самопроверка для сборки/CI; в релиз не входит
plugins\                   каталог плагинов; пустой верхний уровень = только встроенные страницы
```

## 3. Типовые сценарии

### 3.1 Распаковка ресурсов

1. «Файловая система» → «Распаковать»;
2. «Добавить пакет» — выберите `.db0`/`.db1`/`.xdb`/`.sqfs` или перетащите пакет/каталог в окно;
3. нажмите «Загрузить выбранное» — справа появятся записи пакета (ленивая загрузка);
4. можно искать, отмечать отдельные элементы или целое поддерево;
5. проверьте «Распаковать в» — по умолчанию это каталог источника;
6. «Распаковать выбранное» или «Пакетная распаковка»; в строке состояния будет число перезаписанных файлов.

### 3.2 Пакетная перекодировка

1. Укажите исходный путь, целевую кодировку и расширение;
2. при необходимости включите рекурсию, резервные копии и исключения; при указанном каталоге вывода резервное копирование отключается;
3. после запуска смотрите журнал: глубина рекурсии, число файлов, причины пропуска;
4. при неоднозначном автоопределении появится диалог подтверждения (решение, причина, уверенность, имя файла);
5. при ошибке можно «Восстановить копию»; копии лежат в `исходный_каталог\backup\*.bak`.

### 3.3 Сборка пакета локализации

Рекомендуемый вариант через CLI:

```bat
xrkit_cli.exe --font-pack ^
  --ref builtin ^
  --text-root "<каталог перевода>" ^
  --out "<каталог вывода>" ^
  --langs rus ^
  --jsgme --jsgme-name "<имя MOD>" ^
  --patch-offsets 7
```

- `--text-root` может указывать на корень пакета, корень `gamedata` или каталог текстов;
- без `--font` инструмент сам ищет подходящий китайский шрифт по умолчанию;
- `--ref <каталог>` сканирует эталонный пакет: при наличии векторных шрифтов используется векторный путь, при наличии bitmap-текстур — bitmap; при конфликте или отсутствии данных нужно явно указать `--writer`;
- bitmap-атлас не больше **8192**; для крупного набора 50px атлас принудительно расширяется до 8192×4096, без многстраничности и без уменьшения размера;
- участвуют все секции шрифтов (включая пользовательские); базовые HUD/STAT пропускаются;
- для векторного IX-Ray записывается `FontAtlasSize=8192` в `gamedata/configs/engine_external.ltx`;
- необходимость сохранять оригинальные текстуры/английский текст в особых секциях проверяется вручную после сборки;
- для вариативных шрифтов читается ось `wght`: в интерфейсе есть список «Насыщенность» и предпросмотр, по умолчанию 700; доступны значения 100–900.

### 3.4 Обновление

- Поддерживаются только GitHub Release; BETA/RC должны публиковаться как **Prerelease**, стабильные версии — как Release;
- список обновлений сначала запрашивается через GitHub API, при ошибке используется зеркало; пакет сначала берётся с unpkg, затем ghfast/gh-proxy/GitHub;
- загрузка идёт в фоне, прогресс отображается справа от «Готово»; во время загрузки доступна кнопка «Отменить загрузку», частично скачанные данные сохраняются;
- после загрузки программа спрашивает о перезапуске; при выборе «Нет» установка произойдёт при следующем запуске;
- «Инструменты → Проверять обновления» и «Инструменты → Сеть» отключают проверку; параметр `--no-auto-update` также отключает автопроверку;
- замену файлов выполняет `xrkit_updater.exe`, при ошибке выполняется откат; сам updater не использует сеть.

Текущий RC2: `2.0.0.514`; последний опубликованный prerelease: `2.0.0.529 (BETA.269)`. BETA.270 собрана только локально и пока не опубликована.

## 4. Соглашения по ffmpeg для видео

- ffmpeg ищется только в двух местах: `[ffmpeg] path/probe` в `xrkit_user.ltx` или `ffmpeg.exe`/`ffprobe.exe` в каталоге программы/`bin`; PATH не используется;
- поддерживается только **7.x**; в 8.x есть ошибка theora для OGM STALKER;
- в архив входит minimal 7.1.5 ffmpeg без ffprobe; при отсутствии ffprobe автоматически используется `ffmpeg -i`.

## 5. Сборка

```bat
scripts\build.ps1                          :: msvc-release (CLI/движок)
scripts\build.ps1 -Preset msvc-shell       :: GUI + xrkit_smoke
scripts\release.ps1 -Index <номер> -Version 2.0.0 -Mark BETA
```

- Требуются VS 2022 Build Tools, CMake, Ninja, Qt 6.8.3;
- модель C: глобальный `build_counter`, версия тестовой сборки `x.y.z.<build>`, канал используется только как метка;
- `xrkit_smoke.exe` нужен только для сборки/CI и временной самопроверки пакета, в релиз не входит;
- подробности сборки и упаковки — в `docs/ru/build-and-release.md`.

## 6. Известные ограничения

1. **Пути**: CLI и GUI объявляют `activeCodePage=UTF-8` + `longPathAware`; пути длиннее 260 символов всё равно зависят от Windows `EnableLongPaths`.
2. **Плагины в процессе хоста**: падение или побочные эффекты `import` влияют на хост; если главный поток не подаёт heartbeat 30 секунд, срабатывает UI watchdog, пишет `logs/ui_watchdog.log` и завершает процесс (fail-fast, без горячего восстановления). Долгие операции выполняйте в worker `task_run`.
3. **Извлечение текста**: строки скриптов с `--` могут быть пропущены логикой удаления комментариев; см. `docs/ru/known-issues.md`.
4. **Пакет локализации**: при ошибке выполняется откат; не указывайте в качестве каталога вывода корень игры.
5. **Обновления**: BETA.269 загружена в npm (`2.0.0-529`, канал beta); BETA.270 пока не опубликована, клиент откатится на GitHub.

Подробнее — в `docs/ru/known-issues.md`.
