# Руководство пользователя

Здесь описаны основные операции по страницам интерфейса. Команды CLI — в `CLI参考.md`, ограничения — в `已知问题与边界.md`.

## 1. Файловая система

### Распаковка

1. Откройте «Файловая система» → вкладку «Распаковать».
2. «Добавить пакет» поддерживает `.db0`/`.db1`/…, `.xdb`, `.sqfs`; пакет или каталог можно перетащить в окно.
3. После «Загрузить выбранное» справа появятся элементы пакета; дерево загружается лениво, при раскрытии.
4. Поиск фильтрует по мере ввода; щелчок отмечает элемент; отметка папки обрабатывает всё поддерево.
5. «Распаковать в» по умолчанию указывает на каталог источника; проверьте его перед запуском.
6. «Распаковать выбранное» или «Пакетная распаковка»; после завершения строка состояния сообщает число перезаписанных файлов — перезапись не происходит молча.

### Упаковка

1. Перейдите на вкладку «Упаковать», выберите формат и путь вывода.
2. Добавьте входные файлы кнопками «＋Файл»/«＋Каталог»; элементы можно удалить или очистить список.
3. Запустите упаковку; после завершения автоматически выполняется обратное чтение и проверка, при несовпадении числа записей будет ошибка.
4. Символы, не представимые в cp1251, заменяются на `?`; каждая замена попадает в журнал.

## 2. Перекодировка

1. Выберите исходный путь (каталог или файл), целевую кодировку и расширение (по умолчанию `.xml`).
2. При необходимости включите рекурсию, резервные копии и шаблон исключений; при указанном каталоге вывода «Резервная копия» отключается.
3. Запустите перекодировку; журнал покажет глубину рекурсии, число файлов и причины пропуска каждого файла.
4. При неоднозначном автоопределении появится диалог (решение, причина, метка, уверенность, имя файла); отмена означает, что файл не перекодируется.
5. При ошибке можно «Восстановить копию»; копии находятся в `исходный_каталог\backup\*.bak`; «Очистить копии» требует подтверждения.
6. Оболочка задачи поддерживает паузу и отмену; отмена кооперативная — текущий файл сначала завершается.

## 3. Работа с текстом

### Сверка XML

- Сравнение каталогов A/B в режимах «Статистика строк/ID» и «Сравнение текста по ID».
- Статистика сравнивает только наборы ID и число файлов; для поиска изменений текста нужен текстовый режим.
- Результат можно экспортировать в CSV (GUI также в XLSX) и копировать различающиеся ID.

### Извлечение текста

- Режим страницы «Извлечь текст» и `xrkit_cli --extract-text` используют одну реализацию движка.
- В CLI можно указать **корень игры/корень addons**: все `scripts`/`gameplay` находятся автоматически, относительное дерево сохраняется; таблицы текста попадают в `gamedata/configs/text/<lang>/` каждого addon, `--lang` по умолчанию `rus`.
- Конфигурационный XML, корень которого не `string_table`, не считается таблицей текста и не копируется в дерево вывода.
- На выходе создаются `<prefix>_scripts_texts.xml` (или gameplay-версия) и изменённое дерево исходников.
- Поля итоговой строки: `notext` (нет переводимого текста), `skipped` (пропущено), `replskip` (извлечено, но не заменено; должно быть 0), `writefail` (ошибка записи; должно быть 0).

## 4. Видеоконвертер

- ffmpeg ищется только в двух местах: `[ffmpeg] path/probe` в `xrkit_user.ltx` или каталог программы/`bin`.
- Поддерживается только 7.x; в 8.x есть ошибка theora для OGM STALKER.
- ffprobe в архив не входит; при его отсутствии используется `ffmpeg -i`, страница показывает «режим совместимости».
- Если выходной файл совпадает с исходным/эталонным, операция отклоняется; при существующем выходном файле будет задан один вопрос.

## 5. Сборка пакета локализации

1. Выберите каталог текстовых XML (верхнеуровневые `*_texts.xml` и т.п.).
2. Выберите шрифт; если не выбран, инструмент ищет подходящий китайский шрифт по умолчанию.
3. Язык: eng / rus / chs / другое.
4. Размер: стандартный набор создаётся всегда; можно добавить +3, +5, +7, +9, −3, −5.
5. Вариативные шрифты: после выбора шрифта с осью `wght` включается список «Насыщенность», по умолчанию 700; «Предпросмотр насыщенности…» позволяет проверить 100–900. Для статических шрифтов пункт недоступен.
6. Суффикс: нет / `_chs` / свой; это `font_prefix` в `localization.ltx`, он не записывается в `fonts.ltx`.
7. Каталог вывода: результат имеет вид `<вывод>/gamedata/…`; при ошибке сначала используется временный каталог и выполняется откат.
8. Нажмите «Собрать пакет локализации»; в статусе будут число шрифтов, XML и предупреждений.

### Эталонный пакет и IX-Ray

- Версия игры определяется по эталонному пакету: `config` ⇒ SoC; `configs` + DDS 8888 ⇒ ClS; + A8 ⇒ CoP; только `.ttf` ⇒ IXR.
- `--ref <каталог>`: при векторных шрифтах используется векторный путь, при bitmap-текстурах — bitmap; при конфликте или отсутствии данных требуется `--writer`.
- Векторный IX-Ray записывает `FontAtlasSize=8192` в `gamedata/configs/engine_external.ltx`; TTF не перерисовывается; параметр «Насыщенность» в этом пути не используется.
- Bitmap-атлас не больше 8192; для крупного набора 50px атлас принудительно расширяется до 8192×4096, без многстраничности и автоматического уменьшения размера.
- Участвуют все секции шрифтов (включая пользовательские); пропускаются только базовые HUD/STAT.
- Необходимость сохранять оригинальную текстуру или английский текст в особых секциях проверяется вручную после сборки.

### Важно

- При отсутствии глифов по умолчанию выводится предупреждение; строгий отказ — `--on-missing fail`.
- Не указывайте в качестве каталога вывода корень игры: при успехе будут перезаписаны одноимённые файлы в `gamedata`.
- Повторная сборка в тот же каталог удаляет шрифты, которые были созданы в прошлый раз, но больше не создаются (`stale_removed=`).
- «Размер+N» — патч bitmap-шрифтов; IX-Ray `--font-size-patch` меняет только `size` в `fonts.ltx`; это два разных механизма.

## 6. Обновление

- Проверка обновлений выполняется в фоне; прогресс отображается справа от «Готово» в строке состояния.
- Во время загрузки доступна кнопка «Отменить загрузку»; после отмены частичные данные сохраняются и могут быть докачаны.
- После загрузки программа спрашивает о перезапуске; при выборе «Нет» установка произойдёт при следующем запуске.
- «Инструменты → Проверять обновления» отключает всю проверку; «Инструменты → Сеть» отключает сеть хоста.
- BETA/RC обновляются только из Prerelease; стабильные версии — только из обычного Release.

## 7. Плагины

- Плагины кладутся в верхний уровень `plugins\`: `name.py`, `name\plugin.py` или `name\__init__.py`.
- Менеджер плагинов показывает состояние загрузки/отключения; отключённый плагин не загружается, причина отображается.
- Плагины работают в процессе хоста: падение или бесконечный цикл влияют на хост. Если главный поток не подаёт heartbeat 30 секунд, UI watchdog завершает процесс; долгие операции выполняйте в worker.
- API плагинов — в `插件开发.md`.

## 8. Частые ошибки

| Симптом | Что делать |
|---|---|
| Ошибка загрузки: отказ шлюза дешифрования | Зашифрованному пакету нужен плагин-дешифратор или предварительная расшифровка |
| При распаковке ошибка слишком длинного пути | Используйте более короткий корень или включите Windows `EnableLongPaths` |
| После перекодировки текст повреждён | Используйте `auto` или выберите реальную кодировку; сначала проверьте на малом наборе |
| На странице видео нет libtheora | Проверьте ffmpeg 7.x и укажите путь вручную |
| Ошибка сборки шрифтов | Смотрите список отсутствующих глифов в журнале; закройте программу, занявшую каталог вывода |
| Страница плагина пуста | Смотрите ошибки плагинов в `logs`, удалите подозрительный плагин и перезапустите |
