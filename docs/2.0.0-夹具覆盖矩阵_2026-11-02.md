## 二、结论（先不做裁减）

1. **没有一个是纯冗余**：`video_page` / `fs_page` / `toolchain_page` / `xml_page` 各自承担至少一类唯一覆盖；
2. `convert_page` / `fontpack_page` 的覆盖有部分与他处重叠，但**裁掉前必须先确认**：
   `check_thread_contract` 的"取消真停"是否只靠 `convert_page` 这一份夹具；
3. 若要裁：先做**插件页 runtime 判据**（本目标 ①），再按本表第 4 列裁 `convert_page` 或 `fontpack_page`，
   并同步 `check_package_plugin_list` 的显式清单（多一枚/少一枚都红）。
