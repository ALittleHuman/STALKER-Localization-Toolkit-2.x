# 2.0.0 打包与发版规格（M3）

> 用户 2026-09-26 交付链："先补 → 我自己审计+测试 → Hana 审计 → 我实测 → **打包给别人测**"。
> 本文是**发版口径**与**打包判据**；包由 `scripts/package.ps1` 产出。

## 1. 包内 / 包外（一句话：只放"跑起来必需"的，别的都不放）

**包内**：
- `xrkit_app.exe`（`build/msvc-shell` 的 Qt6 外壳）；
- **Qt 运行时**：由官方 **`windeployqt`** 铺（`platforms\`、`styles\`、`tls\` 等）——**不手抄 DLL 名单**，避免漏平台插件；
- `plugins\`：**存在但为空**（既有决策：NLC 解密插件闭源、不随包发布；用户要用自己放进去）；
- `README.txt`（安装/回退/插件/不含什么）、`version.txt`（版本 + 源提交 + 构建时间）。

**包外（明确不放）**：
- **ffmpeg / ffprobe**（视频页要用户自己在页面里**手动指定**，写进 `user.ltx`；口径"只认两处、不搜 PATH"不变）；
- **NLC 解密插件**与任何闭源插件；
- **实验性引擎补丁**（补丁工作线单独走 `PATCHES\` 归档，不进 2.x 发行包）；
- 语料/测试数据/构建中间物。

## 2. 打包判据（不是"看文件齐不齐"，是"从包目录跑得起来"）

`scripts/package.ps1` 在压包**之前**做这一步：把 `qoffscreen.dll` **临时**铺进舞台（`windeployqt` 不会铺它），
然后 `QT_QPA_PLATFORM=offscreen` 从**包目录**跑 `xrkit_app.exe --smoke`，要求输出里出现
`SHELL-SMOKE ok checks=N failed=0`；**跑完删掉那个插件**再压包（发行包保持精简）。

- 实测（2026-09-27）：`PACKAGE OK: dist\STALKER_Toolkit_2.0.0_703f45e.zip`，包内自检 `checks=228 failed=0`。
- 踩到的两个坑（已在脚本注释里写明）：① `windeployqt` **不铺 offscreen 平台插件**；② 原生程序往
  **stderr** 打 Qt 警告时，`$ErrorActionPreference='Stop'` 会把它当终止错误 ⇒ 自检调用要临时用
  `Continue` 并把输出收进日志再挑结论行。

## 3. 安装与回退（写进 README.txt，也写在这里）

- **安装**：整个目录解压到任意位置，双击 `xrkit_app.exe`。
- **回退**：删除该目录即可。本工具**不改动游戏目录里的任何文件**；唯一会写盘的用户设置是
  **`user.ltx`**（主题 / 上次字体 / 手动指定的 ffmpeg），删掉它即恢复默认。
- **失败可见**：插件加载失败**不阻塞启动**，问题会显示在启动后的日志栏里（`plugins\` 目录不存在也不算错）。

## 4. 发版前必做（顺序固定）

1. **`python tests/run_ci.py --release`** —— 抽样档会漏整树缺陷（这一条是 2026-09-27 真机整树跑
   `sqzy_patch` 抓到跨块偏移缺陷后立的规矩）；
2. **`powershell -File scripts/package.ps1`** —— 产出一个**能直接双击跑的目录**（`dist\<主版本>\<标记>\<标记>.<序号>\`，历史按序号共存、不删、不再压 zip），且包内自检必须过；
3. 把**产物目录里各个文件的 sha256**（或整目录指纹）与**源提交**记进交接区材料（给 HanaAgent 审计与用户实测用）；
4. 交付链剩下的三步（**Hana 审计 → 用户实测 → 外部测试**）没走完之前，**不对外发布**。
