# 2.0.0 UI 布局清单（2026-11-11）

本文件只记录**当前实现**，不是历史设计稿。UI 代码分散在 `src/shell/pages/*`、
`page_base.*`、`page_ui_kit.*`、`theme.cpp` 与 `smoke.cpp`；这里是这些文件共同遵守的
布局契约，改 UI 前先看这一页。

## 1. PageBase 结构

```
PageBase (QWidget)
└─ outer_ (QVBoxLayout, margins 12/10, spacing 10)
   ├─ header_row_      标题 + 副标题（固定高，透明）
   ├─ viewport_        ScrollViewport（唯一滚动层）
   │  └─ body_
   │     └─ body_outer_ (QVBoxLayout)
   │        └─ card_ (QFrame#card)
   │           └─ body_layout_ (页面内容)
   ├─ footer_          page_footer（固定高）
   │  └─ footer_layout_ (统计 / 进度 / TaskShell 面板)
   ├─ action_bar_      page_actions（固定高）
   │  └─ action_layout_ = [page_action_status | stretch | 按钮]
   └─ tail stretch     仅 Fit 模式使用
```

### 硬约束

1. **action_bar_ 永远在 viewport_ 外**，不随页面滚动；
2. 窗口压到 `page_min_h()` 时 action_bar_ 必须可见；
3. `viewport_->min_body_height() == page_min_h()`（`minsize_ok()` 判据）；
4. footer 只放统计/进度/任务面板；**状态文字放 action_bar 左侧**，
   与右侧按钮同一行（`add_action_status()`）；
5. 页面内容区只允许一个 stretch 目标。

## 2. Fill / Fit

`PageBase::ContentMode`：

- `Fill`（默认）：viewport 吃满 outer 剩余高度，card 吃满 body；
- `Fit`：窗口足够高时按内容高，action_bar 跟随内容；窗口压矮自动退回 Fill。
  `apply_content_mode()` 里用 `card_->sizeHint()` 与 header/action/margins 计算，
  并以 `height()` 判断。

当前只有**测试夹具**会调 `Fit`；五个内置页默认 `Fill`，因为 fontpack 的 Fit
会改变操作栏位置，和 FS/文本不一致（用户已明确要求三页底部一致）。

## 3. 五页布局

| 页面 | 内容区 | footer | 状态行位置 |
|---|---|---|---|
| FS | `tabs_`（解包/封包）；包/条目两个 `ui::ResultPane` | `task_->panel()` | `task_->status_label()` → action bar |
| XML 文本 | 两个目录行 + 模式行 + `QSplitter`（结果表/详情） | `stats_label_` + `task_->panel()` | `task_->status_label()` 与 `status_` → action bar |
| convert | 路径行 + 选项 + `convert_rows_pane` | `task_->panel()` | `task_->status_label()` 与 `status_` → action bar |
| fontpack | 路径/扫描行 + 选项 + `font_status_pane` | `task_->panel()` | `task_->status_label()` → action bar |
| video | 三个路径行 + `video_info_pane` | `progress_` + `progress_text_` | `status_` → action bar |

### XML 结果/详情

仍使用 `QSplitter`（用户要求保留可拖拽）：

- 详情栏隐藏时 `maximumHeight=0`；
- 分栏 resize 且详情隐藏时，`setSizes({height,0})`，结果表吃满分栏；
- 选中行显示详情，恢复可拖拽。

## 4. 颜色与容器

- 页根：`page_root` property → `surface2`；
- `PageFooter` / `page_header_row` / `page_actions`：透明；
- `page_action_status`：透明；
- `ui::SurfacePanel` / `ResultPane`：`ui_surface` property → `surface2`；
- `QCheckBox/QRadioButton`：透明；
- 列表 viewport：`QTreeView::viewport` → `surface`；
- `QTabWidget` / `QStackedWidget` / `QHeaderView`：`surface2`。

不要再用裸 `QWidget` 承载整行/整块；用 `ui::make_transparent_row()` 或
`ui::ResultPane`。

## 5. 判据

`SHELL-SMOKE` 当前包含：

- 430/800/1111 Fit 夹具（操作栏可见、min_body 契约）；
- 五页 1786×1111 内容区高度；
- `minsize_ok()` / 页顺序 / 操作栏在视口外；
- 文本页结果/详情 `QSplitter` 与详情显隐；
- XML 不丢 ids、untrusted=0。

布局改动后至少跑：


## 6. 已知风险

1. `QSS` 的 padding/border 会改变 `sizeHint`，与 `page_min_h()` 互相影响；
2. 隐藏控件仍可能占 layout item，必须从布局移除或显式 `setMaximumHeight(0)`；
3. `Fit` 不能直接用于有操作栏的普通页，除非同时满足 430 高度契约；
4. 状态标签被 reparent 到 action bar 后，原 TaskShell 面板不再包含它，
   进度条仍在 footer；改 TaskShell 时注意这一点。
