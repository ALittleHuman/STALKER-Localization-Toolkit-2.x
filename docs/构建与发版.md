# 构建与发版

## 1. 环境

| 依赖 | 版本/位置 | 说明 |
|---|---|---|
| Windows | 10/11 x64 | |
| Visual Studio | 2022 Build Tools（MSVC 14.44） | `cl.exe` 不在 PATH，脚本会注入 vcvars 环境 |
| CMake + Ninja | VS 自带（`Common7\IDE\CommonExtensions\Microsoft\CMake\…`） | 脚本自动加进 PATH |
| Qt | 6.8.3 msvc2022_64 | 只 GUI 档需要 |
| Python | 3.14 embeddable（`third_party\python-embed`） | 运行插件/自检用；**不需要系统 Python** |
| 1.x 仓库（可选） | `..\STALKER_Toolkit` | 契约表/golden 的一部分判据要它 |

可覆盖的环境变量：`XRKIT_VS`、`XRKIT_QT`、`XRKIT_PYTHON`、`XRKIT_TOOLKIT_1X`、`XRKIT_SHOWINCLUDES_PREFIX`。

## 2. 两档构建

```bat
scripts\build.ps1                          :: 默认 msvc-release：CLI + engine/core（**不含 Qt**）
scripts\build.ps1 -Preset msvc-shell       :: GUI（xrkit_app.exe）
scripts\build.ps1 -Reconfigure             :: 重新导出 vcvars 环境
```

产物：

```text
build\msvc-release\tools\cli\xrkit_cli.exe
build\msvc-shell\src\shell\xrkit_app.exe
```

> **构建前提**：必须通过 `XRKIT_PYTHON` 指定可用的 Python（embeddable python 或 `py -3`）。
> 未指定时脚本退回 `python`，可能量不出 `/showIncludes` 前缀，导致头文件依赖缺失（改 `.h` 不重编）。

## 3. 打包

```bat
scripts\package.ps1                       :: 打包 + 包内自检
scripts\package.ps1 -PlanOnly             :: 只算"每个文件落到哪"，不动盘
scripts\package.ps1 -Dev:$false           :: 强制发行口径（plugins\ 顶层为空）
```

- 分类规则唯一一份（`Get-PackageDest`），`-PlanOnly` 与真打包共用；
- Qt 运行时用 `windeployqt` 铺；`platforms\` **同时**带 `qwindows.dll` 与 `qoffscreen.dll`；
- **Python 运行期随包**：保留 `_ssl.pyd`/`libssl`/`libcrypto` 与 `sqlite3.dll`/`_sqlite3.pyd`，
  插件可用标准库 HTTPS 与 `sqlite3`；仍剥掉 Qt 的 `Qt6Network.dll`/`tls\`（宿主更新走 WinHTTP 系统组件）；
- 包内写 `README.txt` 与 `version.txt`（版本 + 源提交 + 构建时间）；**不发放 `xrkit_user.ltx`**；
- 打完后**从包目录真跑一次** `xrkit_app.exe --smoke`（`failed=0` 且退出码 0），再查包内 exe 的
  VERSIONINFO 与 sha256、`--python-host` 的 `gil=released`、IX-Ray `--selftest`。

## 4. 发版

```bat
scripts\release.ps1 -Index 246 -Version 2.0.0 -Mark BETA
```

四步（脚本会逐步校验）：

1. `xrkit_cli --write-version 2.0.0 BETA 246`（改 `version.h` 与 `.rc`，不动 `version.json.current`）；
2. `build.ps1` 两档（此时没有进程占用 `xrkit_cli.exe`）；
3. `xrkit_cli --build-package version.json 2.0.0 BETA 246 --prebuilt`（只算 sha + 打包 + 收尾）；
4. 校验包内 `version.txt` / `xrkit_cli --version` / 包内 app 的 VERSIONINFO 三者一致。

产物：`dist\2.0.0\BETA\246\`（旧序号目录保留；重建同序号＝覆盖该序号自身）。

## 5. 门禁（提交前至少跑前两道）

```bat
:: 1) 三层门禁
third_party\python-embed\python.exe tests\run_ci.py            :: local 全量
third_party\python-embed\python.exe tests\run_ci.py --fast     :: 公开 CI
third_party\python-embed\python.exe tests\run_ci.py --release  :: 发版（任何 SKIP 即 FAIL）
:: 2) GUI 自检
set QT_QPA_PLATFORM=offscreen && build\msvc-shell\src\shell\xrkit_app.exe --smoke
:: 3) 单项检查器（示例）
third_party\python-embed\python.exe tests\check_audit_p0_guards.py
third_party\python-embed\python.exe tests\check_host_update_poll.py
third_party\python-embed\python.exe tools\gen_winres.py --check
```

规则（很重要）：

- **仓库自带的门禁文件缺件 = FAIL**（不许"删掉门禁文件变绿"）；
- **外部前提缺件（MSVC/真机样本/1.x 仓库）= SKIP + 记入未覆盖清单**；`--release` 下任何 SKIP 即 FAIL；
- 每个 checker 约定退出码 `0/1/2`（PASS/FAIL/SKIP）与固定收尾行。

## 6. 排障

| 现象 | 处理 |
|---|---|
| `configure` 卡在 "Detecting CXX compiler ABI info" | 检查是否在全权文件模式（沙箱会让 cmake→ninja→cl 链死锁） |
| 改了 `.h` 不重编 | 设 `XRKIT_PYTHON` 后 `-Reconfigure`；看 `.ninja_deps` 是否含头文件 |
| `vcvars 环境导出失败` | 检查 `XRKIT_VS` 路径下 `VC\Auxiliary\Build\vcvars64.bat` |
| 包内自检 `failed=1` | 先看 `logs`；常见是缺 `qoffscreen.dll` 或漏了 Python 运行库 |
| 契约表 `--check` 失败 | 1.x 仓库路径不对；设 `XRKIT_TOOLKIT_1X` |
