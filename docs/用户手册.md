# 用户手册（图形界面）

适用：`xrkit_app.exe`（2.0.0 系列；版本以包内 `version.txt` 或 `--version` 为准）。界面按页签组织，五个内置页：**文件系统 / 编码转换 / 文本工具 / 视频转换 / 汉化包生成**。
每页底部是任务区（进度、状态、日志），跨页一致：**任何"跳过/覆盖/改名/截断"都会写在状态或日志里**，不会静默。

> 通用规则
> - 拖放：能拖的输入框/区域会把**本机文件路径**填进去（目录也有对应页面接住）。
> - 任务：同一页同时只能跑一个任务；点「取消」后要等状态行给出结论再继续操作。
> - 日志：界面每一行都写进 `logs\log_*.txt`，反馈问题请附该文件。

## 一、文件系统（解包 / 封包）

两个标签：**解包**、**封包**。左侧是包列表（包名/大小/行尾 ✕），右侧是条目树（包内条目/大小/来源）。

### 解包

1. **加包**：点「加包」→「选包文件…」或「选文件夹…」；也可把包/文件夹拖进窗口。
   一个文件夹会被当作"散装目录"直接列条目；目录里的包会被识别成多个包。
2. **加载**：点行选中（可多选），再点「加载选中」；已加载的包会显示条目。
   「全选」是**选中**而不是勾选（和条目树的勾选是两套概念）。
3. **看条目**：条目树懒加载——展开文件夹才读它的子项；顶部搜索框**边打边筛**；
   单击文件夹=展开，单击文件=勾选（再点取消）；勾文件夹会级联到整棵子树。
4. **解包**：设定「解包到」后点「解包选中」（只解勾选的）或「批量解包」（解整包）。
   - **默认落点是来源所在目录**，直接点开始会落在游戏/模组目录里——先确认；
   - 落点规则：`<输出>/<包名>/…`（包名去掉最后一个扩展名；包内自带目录壳时不会叠第二层）；
   - 完成后状态行会报**覆盖了多少个文件**（覆盖是可见的）；
   - 读不出来的条目会逐条给理由；条目表被截断时会单独提示"已截断"，那不是失败。
5. **移除源**：点行尾 ✕（只摘掉这一行，不删文件）。

### 封包

1. 选格式（**不提供 auto**）、输出路径（可点「选择…」）；
2. 用「＋文件」「＋目录」把要打的内容加进待打包列表（可多选，用「移除」「清空」调整）；
3. 点「封包」。完成后会报文件数与字节数；
4. 若包里有 cp1251 表示不了的字符，名字会被改写成 `?`——**每条改写都会逐条列在日志里**，
   不想要就先把文件名改掉再封。

### 注意

- 加密包/解密插件：没有对应插件时，加密包会**拒绝加载并给理由**，不会产出坏包；
- 封包格式与扩展名约定：DB 用 `.db0/.db1/…`（按格式），SquashFS 用 `.sqfs`；输出没写扩展名时会按格式补；
- 极难压缩的数据可能触发 LZHUF 上限错误（见 `已知问题与边界.md`）。

## 二、编码转换

### 一次转换

1. **源路径**：选目录（递归）或单个文件；**输出目录留空＝原地转换**（会先备份，见下）。
2. **源编码 / 目标编码**：源侧默认 `auto`（六步检测链），目标侧多一个 `ascii`。
3. **扩展名**（默认 `.xml`，逗号分隔）、**递归**（默认开）、**备份**（默认开）、**排除模式**。
   - 填了输出目录后，「备份」会**自动取消勾选并禁用**（备份只对原地转换有意义）。
4. 点「开始转换」。开始前会显示**扫描台账**：递归几层、目录/文件各多少、后缀不符/命中排除/备份区各刷掉多少。
5. 自动判定不确定时弹**确认框**：判定、理由、标记、置信度、文件名。答否＝该文件不转换。
6. 完成后状态行给出「成功 / 跳过 / 失败」计数；失败逐条有理由。

### 暂停、取消、备份

- **暂停/继续**：页面自己的门闸，暂停时引擎在文件边界停住；暂停中取消同样生效。
- **恢复备份**：把 `源目录\backup\**\*.bak` 逐条恢复（原文件不存在会记为失败并给理由）。
- **清空备份**：删除 `backup` 目录内容；没有备份目录会明说"无需清空"。
- **打开输出**：打开输出目录（或源目录）；打不开会提示"可能缺少文件管理器关联/权限不足"。
- **导出统计**：把本次计数与耗时写成 CSV（含时间戳、编码、候选/处理/成功/跳过/失败）。

### 注意

- 同一个文件被两个任务同时处理会失败（请等上一个任务结束）；
- 单文件转换建议填写输出目录；原地转换 + 备份的组合对单文件输入不适用（见 `已知问题与边界.md` §6）。

## 三、文本工具（XML 校对 + 文本提取）

1. 选两个文件夹 A / B，各自选编码（`auto` 或显式）。
2. 选**模式**：统计 / ID 文本 / **提取文本**，以及**筛选**（全部 / 仅不一致 / 仅一侧存在）。
   - 「行数/ID 统计」（`stats`）只比 ID 集合与文件数；要看文本改动选「ID 文本对比」（`text`）；
   - 「**提取文本**」：一侧目录留空时出现（选项行默认隐藏）。勾选要产出的内容
     （文本形式 XML、改写后的脚本/配置），点开始后从 `scripts` / `gameplay` / `.ltx`
     抽取可译文本，产出 `<prefix>_scripts_texts.xml` 与改写后的源码树。
     `--prefix` 等细节与输出字段契约见 `CLI参考.md` §3（页面调的是同一个引擎实现）。
3. 点「开始比较」。结果表列由模式声明决定（相对路径/状态/行数/差异数/明细…）；
   每行状态：`一致` / `不一致` / `仅 A` / `仅 B`，不可信时缀「（不可信）」。
4. 点一行看**明细**（由工具统一生成）；每行的「复制」按钮把该行差异 ID 写进剪贴板
   （复制失败会把 ID 原文留在状态行，方便手动复制）。
5. 「导出 Excel」出 `.xlsx` 报告（按钮默认落点）；CSV 由命令行导出提供（界面不直接给 CSV 按钮）。
   比较进行中导出会被拒绝。
6. 「清除」只清空两个输入框（结果表保留）；**取消在文件边界生效**，表里每一行都是完整结果。

## 四、视频转换（→ OGM）

三行：**源文件 / 参考 OGM / 输出 OGM**，每行可拖入或点「选择…」。

1. 选源视频（mp4/avi/mkv/mov…），选参考 OGM（决定帧率/分辨率/码率/声道）；
2. 点「检测 ffmpeg」：只认两处——`xrkit_user.ltx` 的 `[ffmpeg] path/probe`，或程序目录/`bin` 下的
   `ffmpeg.exe`/`ffprobe.exe`；**不搜 PATH**。找不到会列出试过的路径；也可点「设置 ffmpeg」手动指定。
3. 信息面板会显示源/参考的参数与**引擎给出的转换参数**（缩放/帧率/码率/声道/是否静音）。
   这些参数以参考 OGM 为准，页面不自己再判一遍。
4. 输出：默认取"参考所在目录 + 同主名"；与参考同名时自动改 `.new.ogm`；手改过输出框不会被覆盖。
5. 点「转换为 OGM」：
   - 输出 == 源 或 == 参考 ⇒ **直接拒绝**（不会弹确认）；
   - 输出已存在 ⇒ **问一次**，答否不跑；
   - 进度来自 ffmpeg stderr（上限 99.5%，完成后置 100%）；
6. 「取消」会真停进程；5 秒不退会明确报"取消超时"并清掉半成品（删不掉也会说）。

版本闸门：**只接受 7.x**；8.x 会直接拒绝并提示原因。

## 五、汉化包生成

用于把"文本 XML 目录"变成可安装的字库 + 配置包，也可生成 IX-Ray 矢量字库补丁。

1. **文本 XML**：只扫**顶层**（`*_texts.xml` 之类）；点「选择…」选目录。
2. **字体**：点「选择…」打开字体选择器（系统字体列表 + 四态标记 + 预览 + 缩放 + 「浏览其他目录…」）；
   未选时按默认顺序找 NotoSansSC → 微软雅黑。
3. **游戏 / 语言 / 字号 / 后缀 / 包含完整西里尔**：
   - 游戏：SoC / ClS / CoP / IX-Ray；
   - 语言：eng / rus / chs / 自定义；
   - 字号：多选——「标准（始终生成）」固定勾选，另有 大/+3、大/+5、大/+7、大/+9、小/−3、小/−5；
   - 后缀：无 / _chs / 自定义。
4. **输出目录**：产物是 `<输出>/gamedata/…`（字库、配置、字体表）；「打开输出目录」可直接查看。
5. 点「生成汉化包」（可先点「检测字体」看缺字/状态）：失败不会动你已有的 `gamedata`
   （先写临时目录，成功才合并；中途失败会回滚）；完成状态给出字体数、XML 数、告警条数。
6. **IX-Ray**：游戏选 IX-Ray 后，需要在「参照包」里选一个原始结构的整包（fonts.ltx / textures / addons），
   可点「扫描参照包」自动识别档位与语言；该模式只改 `configs/fonts.ltx` 的 size，TTF 不重烘。

### 注意

- 缺字默认只警告；要严格失败用命令行 `--on-missing fail`；
- 输出目录**不要直接指向游戏根**：虽然失败会回滚，但成功时会覆盖 `gamedata` 下同名文件；
- 「大/+N」「小/−N」补丁与 IX-Ray 矢量补丁是两套东西（前者是位图字库，后者只改 `fonts.ltx` 的 size）。

## 六、常见错误与处置

| 现象 | 原因 | 处置 |
|---|---|---|
| 加包后"加载失败：解密闸门拒绝" | 加密包且没有解密插件 | 放对应插件到 `plugins\`，或先解密 |
| 解包报「拒绝落盘：问不出落点的属性（stat 失败）」 | 包内深层路径 >260 字符（无长路径清单） | 解到更短的根（如 `D:\x\`），不要解到"我的文档"深层 |
| 转换后文本乱了 | 源编码选错 | 用 `auto` 或按文件实际编码选（俄版常见 windows-1251）；先在小样本上试 |
| 视频页「没有 libtheora 编码器」 | ffmpeg 未找到或版本不对 | 「检测 ffmpeg」确认 7.x；或「设置 ffmpeg」手动指定 |
| 汉化包生成"字库失败" | 字体缺字形/输出被占用 | 看日志里的缺字清单；关掉占用输出的程序 |
| 界面某页空白/占位 | 插件页面加载失败 | 看 `logs` 里的插件错误；移除可疑插件重启 |

更多限制见 `已知问题与边界.md`。
