# 用户手册

本手册按界面页面说明常用操作；命令行见 `CLI参考.md`，限制见 `已知问题与边界.md`。

## 一、文件系统

### 解包

1. 打开「文件系统」→「解包」标签。
2. 「加包」支持 `.db0`/`.db1`/…、`.xdb`、`.sqfs`，也可以把包或文件夹拖进窗口。
3. 点「加载选中」后右侧出现包内条目；树是懒加载，展开时才读。
4. 搜索框边打边筛；单击条目勾选/取消；勾文件夹会处理整棵子树。
5. 「解包到」默认是来源所在目录；请先确认。
6. 「解包选中」或「批量解包」；完成后状态行报覆盖数量，覆盖不是静默的。

### 封包

1. 切到「封包」标签，选格式和输出路径。
2. 用「＋文件」/「＋目录」加入输入；可移除或清空。
3. 开始封包；完成后会自动回读自检，条目数不符会报错。
4. 文件名里 cp1251 表示不了的字符会被改写成 `?`，逐条列在日志。

## 二、编码转换

1. 选源路径（目录或单文件）、目标编码、扩展名（默认 `.xml`）。
2. 可选递归、备份、排除模式；填了输出目录时「备份」自动失效。
3. 开始转换；扫描台账会写清递归层数、文件数、各文件为什么被跳过。
4. 自动判定不确定时会弹确认框（判定、理由、标记、置信度、文件名）；取消即不转换。
5. 出错可「恢复备份」；备份在 `源目录\backup\*.bak`；「清空备份」需确认。
6. 任务壳支持暂停/取消；取消是协作式的，当前文件处理完才停。

## 三、文本工具

### XML 校对

- 目录 A/B 比对，模式有「行数/ID 统计」和「ID 文本对比」。
- 统计模式只比 ID 集合与文件数；找文本改动要选文本模式。
- 结果可导出 CSV（GUI 也可导出 XLSX），可复制差异 ID。

### 提取文本

- 页面模式「提取文本」与 `xrkit_cli --extract-text` 共用同一份引擎实现。
- 输出 `<prefix>_scripts_texts.xml`（或 gameplay 版）和改写后的源码树。
- 汇总行字段：`notext`（没有可译文本）、`skipped`（跳过）、`replskip`（提取到但没替换上，应为 0）、`writefail`（写回失败，应为 0）。

## 四、视频转换

- 只认两处 ffmpeg：`xrkit_user.ltx` 的 `[ffmpeg] path/probe`，或程序目录/`bin`。
- 只接受 7.x；8.x 的 theora 对 STALKER OGM 有 bug。
- 发行包不带 ffprobe；缺 ffprobe 时自动用 `ffmpeg -i`，页面会标「已降级」。
- 输出等于源/参考会直接拒绝；输出已存在会问一次。

## 五、汉化包生成

1. 选文本 XML 目录（顶层 `*_texts.xml` 等）。
2. 选字体；未选时自动找 NotoSansSC → 微软雅黑。
3. 语言：eng / rus / chs / 自定义。
4. 字号：标准固定生成；可加 大/+3、+5、+7、+9、小/−3、−5。
5. 后缀：无 / `_chs` / 自定义；它是 `localization.ltx` 的 `font_prefix`，不写进 `fonts.ltx`。
6. 输出目录：产物是 `<输出>/gamedata/…`；失败会先写临时目录并回滚。
7. 点「生成汉化包」；完成状态给出字体数、XML 数、告警数。

### 参照包与 IX-Ray

- 游戏版本由参照包判定：`config` ⇒ SoC；`configs` + DDS 8888 ⇒ ClS；+ A8 ⇒ CoP；只有 `.ttf` ⇒ IXR。
- `--ref <目录>`：有 TTF 走矢量，有 `ui_font_*.dds` 走位图；证据冲突/缺失时要求 `--writer`。
- IX-Ray 矢量路径会在 `gamedata/configs/engine_external.ltx` 写 `FontAtlasSize=8192`，TTF 不重烘。
- 位图单图集最多 8192；50px 大字集硬扩到 8192×4096，不做多页或自动降字号。
- 所有 `ui_font_*` 段都参与生成（含 electron/`ui\fonts\` 下的自定义段）；只有 `hud*`/`stat_*` 基础字体跳过。
- 特殊字体（如 electron）是否保留原贴图或让引用文本保持英文，由生成后人工复核。

### 注意

- 缺字默认只警告；严格失败用 `--on-missing fail`。
- 输出目录不要直接指向游戏根：成功会覆盖 `gamedata` 下同名文件。
- 重新生成到同一目录会清理上次生成、这次没再生成的字库（`stale_removed=` 报数）。
- 「字号+N」是位图字库补丁；IX-Ray `--font-size-patch` 只改 `fonts.ltx` 的 size，两套机制。

## 六、更新

- 检查更新后台进行；进度显示在状态栏「就绪」右侧。
- 下载中有「取消下载」按钮；取消后保留分片，下次可续传。
- 下载完成询问是否重启安装；选「否」则下次启动安装。
- 「工具 → 启用检测更新」关闭整个检测更新；「工具 → 联网功能」关闭宿主联网。
- BETA/RC 只从 Prerelease 更新；正式版只从正式 Release 更新。

## 七、插件

- 插件放 `plugins\` 顶层：`name.py` 或 `name\plugin.py`/`name\__init__.py`。
- 插件管理器可查看加载/禁用状态；被禁用的插件不会加载并显示原因。
- 插件与宿主同进程：崩溃或死循环会影响宿主。主线程 30 秒无心跳会触发 UI 看门狗并退出进程；长活请用任务 worker。
- 插件 API 见 `插件开发.md`。

## 八、常见错误

| 现象 | 处置 |
|---|---|
| 加载失败：解密闸门拒绝 | 加密包需要解密插件，或先解密 |
| 解包报路径过长 | 换短根目录，或打开 Windows `EnableLongPaths` |
| 转换后文本乱码 | 用 `auto` 或选实际编码；先小样本验证 |
| 视频页没有 libtheora | 确认 ffmpeg 7.x，手动指定路径 |
| 字库生成失败 | 看日志缺字清单；关闭占用输出的程序 |
| 插件页空白 | 看 `logs` 的插件错误，移除可疑插件重启 |
