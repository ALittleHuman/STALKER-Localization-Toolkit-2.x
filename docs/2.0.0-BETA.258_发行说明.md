## 二、这个版本改了什么

### 1. P5「插件页空页」的根因修复（ALPHA.253 起）
不是视口/外壳问题，而是**页容器地址复用后被门面判死**：容器 `new QWidget` 从不登记进句柄表，
地址一旦复用某个**已销毁**门面控件的地址，`unwrap()` 就把活容器当死句柄 ⇒ `resolve_parent()` 返回 null
⇒ 整页控件无父 ⇒ 占位页。
修法：`adopt_host_widget()`（覆盖写）+ **`make_host_widget()` 工厂**（`hub.cpp` 两处根容器改用它）
+ 静态锁 `tests/check_host_widget_adopt.py`（自带反例自证）。
实测：`root_stale=1` 从 **60/10 次** 降到 **0**；伴随的 8 条连带红（P17-82×4 / P16-3b-2 / P16-3c / P4×2）消失。

### 2. ⑭「标签背后深灰底板」改成三态
`PASS` / `PRODUCT_FAIL`（有预期行却 0 行，或标签带涂底）/ **`NOT_COVERED`**（判据主体不存在，或对照组全 0）
＋ 逐页**预期字段行数**（fs 1 / convert 2 / text 2 / xml 2 / video 3 / fontpack 3）＋ **内置 fs 页当对照组**。
"**不适用**"（页本来就没有字段行）只记 note，**不**计未覆盖 —— 否则消费侧永远拿不到 PASS，反而逼人放宽判据。
收尾行新增 `not_covered=K`；判据脚本 `check_package_fixture_pages.py` 认它：K>0 ⇒ 打 `!!` + 记台账 + 退 2，
**不静默算通过**。

### 3. 顺带转绿的三条存量静态锁（ALPHA.252 上本来就红）
`builder-guard`（settle 诊断搬家让 `catch` 紧贴 builder 调用点）、`page-host` ④（ctor 显式 `sync_pages()`）、
`px-only` 白名单行号漂移（81/164 → 91/174，同一处违规）。

### 4. 修掉一条夹具竞态（P4 `task_run` 2/30）
L2 夹具的 `mark()` 由 build 线程与 worker 线程共用一个句柄且无锁 ⇒ 读者可能先看到 worker 行、后看到主线程行。
修法：夹具 `mark()` 加锁 + 锁内 flush；判据改成**完成条件**（等 `run:1` 出现再判，不固定 sleep）。

## 三、★ 兼容性与迁移（必读）

**1.x 插件不保证直接加载，需自行移植。**
依据：2.x 的插件接口是 Python `register(api)` + `api.ui.*`（16 方法契约），
1.x 是 `TkUiFactory`/`api.widgets`；两者**参数名与语义**有差异（契约表见 `include/xrkit/engine/plugin/widget_facade.h`
与门禁 `check_ui_contract_params.py`）。1.x 插件目录里的 `.dll` 也不在 2.x 的扫描范围（C ABI 已退役）。
⇒ 移植清单：① 把 `register(panel)` 改 `register(api)`；② 控件调用换成 `api.ui.*`；
③ 生命周期回调改成 `task_on_message` / 主线程收尾（worker 里不许碰控件）。
