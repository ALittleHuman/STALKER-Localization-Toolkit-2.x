## 三、给新会话的"避坑提示"（都是我这几轮真踩过的）

1. **补丁脚本里中文引号一律用 `「」`** —— 在双引号串里嵌 ASCII 双引号会直接 `SyntaxError`（**我犯过 6 次**，每次整包不落地）；执行前先 `ast.parse` 脚本自身。
2. **改前先 `read` 出确切原文再整段替换**，别用"向上找最近的 def"或"按大括号猜切"（我用后者把 `screen_scale.cpp` 切坏过一次，`C2059`）。
3. **一次只改一处 → 立刻编译 + 跑该步判据**；构建失败时 `--only selftest` 跑的是旧二进制（**假绿**）。
4. **`ui_*.h` 是 Qt AUTOUIC 的禁忌命名**（`.gitignore` 里那条就是为此）；新头文件避开 `ui_` 前缀。
5. **红着不提交**；未验证的改动不要留在闸门里（宁可 `git checkout -- <file>` 精确撤回）。
6. 门禁里 `px-only` / `no-console` 是两条**独立静态锁步骤**（我做的时候先把它们**证明被执行**再谈别的）。
