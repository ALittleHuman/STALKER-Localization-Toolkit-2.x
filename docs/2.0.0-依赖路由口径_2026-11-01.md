# 2.0.0 依赖路由口径（用户 2026-11-01 拍板，DSH 落地）

## 一、先纠正一处：写的是 `xrkit_user.ltx`，不是 `user.ltx`

本工具的设置文件是 **`xrkit_user.ltx`**（app 目录）。`user.ltx` 是**游戏**配置，
本仓只在硬条件下读一次做迁移（`theme.cpp`），**从不写**、也不进包。
所以 `[runtime]` 段写在 `xrkit_user.ltx` 里；"正式版只改这一段"这条纪律照旧成立。

## 二、两类依赖（边界不能混）

| 类别 | 成员 | 能否走 `[runtime]` |
|---|---|---|
| 可路由 | `ffmpeg`（必需；**BETA.85 起随包的是自建 minimal 7.1.5，5.06 MB**，只含 OGM 转码白名单）、`ffprobe`（**可选**；P-798 起不随包带，缺了走 `ffmpeg -i` 降级）、IXR 的 `python`、`ixr_run.py`、`fontlib/fontTools` | ✅ |
| 加载器级 | Qt6*.dll、主程序嵌入式 `python314.dll` | ❌ 只能放工具目录（改加载器不划算） |

## 三、解析优先级（用户钉死，**不许 PATH 兜底**）

1. 单项显式：`[runtime] ffmpeg = ...`（支持 `@APP@` 与 `${root}`）
2. `[runtime] root` + 约定子路径（`bin/ffmpeg.exe`、`python/python.exe`、`tools/ixr_run.py`、`tools/fontlib`）
3. 工具目录默认（`<app>/bin/...` 等；**老包根目录 ffmpeg 仍然优先于 bin**，D4-3 不变）
4. 都没有 ⇒ 空 + 调用方明确报错（`--runtime-paths` 退出码非 0）

## 四、形态

迭代期（10 个构建共享一套运行时）：

```
D:\\STALKER\\runtime\\2026-10\\
  bin\\ffmpeg.exe  bin\\ffprobe.exe
  python\\python.exe
  tools\\ixr_run.py  tools\\fontlib\\fontTools
```

```ini
; <每个构建>/xrkit_user.ltx
[runtime]
root = D:\\STALKER\\runtime\\2026-10
```

正式版（打包时**只写这一段**）：

```ini
[runtime]
root = @APP@        ; @APP@ 运行时展开为工具目录，不写死盘符
```

## 五、已落地（BETA.53/54）

- `core::runtime`（`include/xrkit/core/runtime.h`、`src/core/runtime.cpp`）：token 展开、
  `runtime_root()`、`resolve_runtime_dep()`（返回 path + source=explicit/root/app/missing）；
- CLI `--runtime-paths <工具目录>`：打印 5 项依赖的实际路径与来源，缺件时退出码非 0；
- `video::find_ffmpeg`：`[ffmpeg] path/probe`（旧显式键）→ runtime 显式/root → 工具根 → `bin/`；
- `font::ixr`：`XRKIT_IXR_*` 环境变量 → runtime（显式/root）→ 工具目录；
- `scripts/package.ps1`：**排除**开发机的 `xrkit_user.ltx`；打包时在 stage 写
  `[runtime] root = @APP@`（保留其它段）；并做**开发路径泄漏检查**（出现 `X:\\` 直接 throw）。

## 六、判据

`tests/check_runtime_routing.py` + 门禁步 `runtime-routing`：
`root` 共享 runtime、`@APP@` 展开、单项显式优先、全缺明确报错（退出码非 0）。
打包侧另有两条：包内 `xrkit_user.ltx` 存在且只有 `[runtime] root = @APP@`；泄漏检查。

## 七、风险（用户点名，逐条对应）

| 风险 | 现有兜底 |
|---|---|
| 开发路径泄漏进正式版 | `package.ps1` 扫 `X:\\` 直接 throw；`--runtime-paths` 可复查 |
| 共享 runtime 版本漂移 | 版本守卫仍"恰好 7.x"；待办：runtime 目录带哈希、由门禁锁定 |
| 路径含空格/中文/UNC | `@APP@` 展开走 `std::filesystem`；**尚无专门夹具**（待办） |
| `xrkit_user.ltx` 被整体覆盖 | 打包只重写 `[runtime]` 段，其它段原样保留 |
| Qt/Python 被误当可路由 | 文档与 `resolve_runtime_dep` 只服务 5 项；Qt/内嵌 Python 不在列表 |
